# 三维立体图（geom3d）—— 立项

## 为什么做

现有的数学图形只存**二维**顶点，一条棱该实线还是虚线只能靠**启发式猜**：
沿线段采样墨迹看断不断、凸包内外、虚线样式……实测为了「补出来的线该实该虚」来回试了三版，
其中两版还会伤真值集（配上边 67→65、虚实 62→60）。

立体几何里虚虚实实**是算出来的**：凸多面体的一条棱，只要属于至少一个「正面朝向的面」就是可见的。
有了三维模型 + 面表，下面三类问题在架构上就不存在：

1. **多余顶点**（投影上异面直线假交叉、字母切断线留下的断口顶点）；
2. **虚实判错**；
3. **异面直线在投影上看着相交**（用户那幅棱柱里 D₁A₁ 与 C₁C 就是典型）。

## 现在的状态（v2026.09.1163）

**模块**：`src/composables/geom3d.ts` —— `projectGeom(model, view)`

- 输入：三维顶点 + 面表（+ 辅助线）；视角 azim/elev
- 做：正交投影 → **按面表算每条棱的可见性**（凸体：属于至少一个正面朝向的面即可见）→
  输出跟 `MathFigureElement` 的 `points / mesh / vlabels` **同一套结构**
- 所以**渲染、导出、拖点全部复用现有那条路**，不加新元素类型

**已验证**：拿用户那幅 13 点棱柱（4×3 + P）当靶子，azim -35 / elev 20 ——
立方体被挡的三条棱自动虚线、C₂ 发出的四条辅助线自动虚线，跟原图一致 ✓

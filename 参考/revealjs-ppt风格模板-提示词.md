# Reveal.js「PowerPoint 风」模板生成提示词

> 用途：让 AI 生成视觉上与 Microsoft PowerPoint 桌面版一致的 Reveal.js 幻灯片模板。
> 三大原则：**设计令牌集中制 + 母版版式制 + 负面清单**。
> 【】内为可定制参数，用前先替换。

---

## 一、主提示词（生成整套模板时使用）

```text
你是一名资深幻灯片模板工程师，精通 Microsoft PowerPoint 桌面版的视觉规范
与 Reveal.js 4.x 的主题机制。请为我制作一套 Reveal.js 幻灯片模板，要求成品
"看起来就是一份标准的 PowerPoint 演示文稿"，而不是 AI 生成的网页。

━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 设计令牌（唯一允许的样式来源）
━━━━━━━━━━━━━━━━━━━━━━━━━━
所有颜色、字体、字号、间距必须先在 :root 中定义为 CSS 变量，任何幻灯片
页面只能引用变量，禁止出现字面量颜色或令牌表之外的字号。

:root {
  /* 配色：遵守三色原则 = 1 主色 + 1 强调色 + 灰阶 */
  --ppt-bg: #FFFFFF;              /* 页面底色，纯白或极浅灰 */
  --ppt-text: #1F1F1F;            /* 正文深灰黑（PPT 默认非纯黑）*/
  --ppt-text-light: #595959;      /* 次要文字 */
  --ppt-accent: 【主色，如 #4472C4】;       /* 标题/强调，Office 经典蓝 */
  --ppt-accent-dark: 【主色加深，如 #2F5597】;
  --ppt-divider: #D9D9D9;         /* 细分割线 */
  --ppt-footer: #8C8C8C;          /* 页脚页码 */

  /* 字体：中文办公场景字体栈 */
  --font-body: "Microsoft YaHei", "等线", "PingFang SC", "Segoe UI", Calibri, sans-serif;
  --font-heading: var(--font-body);   /* PPT 中标题正文同族，只靠字号字重区分 */
  --font-code: Consolas, "Courier New", monospace;

  /* 字号阶梯（基于 1280×720 画布，全片只允许这些值）*/
  --fs-title: 36px;   /* 内容页标题，加粗 */
  --fs-h2: 26px;      /* 二级标题 */
  --fs-body: 20px;    /* 正文，行高 1.45 */
  --fs-caption: 16px; /* 图注/页脚 */
  --fs-cover: 52px;   /* 封面主标题 */

  /* 间距阶梯（只允许这些值）*/
  --gap-xs: 8px; --gap-s: 16px; --gap-m: 24px; --gap-l: 40px;
  --page-margin: 60px;  /* 版心四边距 */
}

━━━━━━━━━━━━━━━━━━━━━━━━━━
2. 版面规范（模仿 PowerPoint 默认行为）
━━━━━━━━━━━━━━━━━━━━━━━━━━
- 画布：16:9，width=1280, height=720。
- 版心：四周边距 60px；内容区宽 1160px。
- 对齐：内容**顶部对齐**（PowerPoint 默认不垂直居中），
  Reveal 配置必须写 center: false。
- 标题：内容页标题位于版心左上角，var(--fs-title) 加粗，
  下方可加 2px 高、80px 宽的强调色细横线（唯一的标题装饰）。
- 页脚：右下角页码（--fs-caption, --ppt-footer），
  左下角可放【机构名/课程名】，与页码同色。
- 装饰上限：整页装饰仅限——标题下细横线、封面/章节页角部一个
  强调色小矩形色块。除此之外不加任何装饰。

━━━━━━━━━━━━━━━━━━━━━━━━━━
3. Reveal.js 技术要求
━━━━━━━━━━━━━━━━━━━━━━━━━━
- Reveal.js 4.x；不引入任何内置主题（不用 black/white/sky 等），
  全部样式走自定义 theme.css。
- 自定义样式必须覆盖 .reveal、.reveal .slides、.reveal .controls、
  .reveal .progress，确保控件颜色与主色一致。
- 配置：transition: 'slide'（或 'none'），center: false，
  width: 1280, height: 720, margin: 0。
- 字号一律用 px（画布固定 1280×720，靠 Reveal 自带 scaling 缩放，
  不用 rem/vw，避免不同屏幕字号漂移）。
- 需兼容 print-PDF 导出（deck.print.js 或 ?print-pdf）。

━━━━━━━━━━━━━━━━━━━━━━━━━━
4. 必须提供的 7 种母版版式
━━━━━━━━━━━━━━━━━━━━━━━━━━
每版式做成一个 <section> 示例页，配 class 命名（layout-cover /
layout-section / layout-list / layout-two-col / layout-figure /
layout-quote / layout-end）：
  1. 封面：主标题 + 副标题 + 日期/作者，左对齐，角部色块
  2. 章节页：超大强调色章节号（01/02…）+ 章节名
  3. 标题 + 要点列表（列表符号用强调色小方块或圆点）
  4. 标题 + 左右双栏
  5. 标题 + 图/表（图片等比缩放居中，图注 --fs-caption）
  6. 引用页：大引号 + 引文 + 出处（无背景色块，只用左粗竖线）
  7. 结尾页：「谢谢」+ 联系方式，与封面同构
所有版式共享同一条页脚规则。

━━━━━━━━━━━━━━━━━━━━━━━━━━
5. 负面清单（出现任何一条即为不合格）
━━━━━━━━━━━━━━━━━━━━━━━━━━
- ❌ 渐变背景、渐变文字、渐变按钮
- ❌ 玻璃拟态、毛玻璃、大圆角(>8px)卡片层层嵌套、外发光、投影
- ❌ 用 emoji 当图标（🚀✨💡 等）
- ❌ 同一页出现 3 种以上彩色；跨页换配色
- ❌ 令牌表之外的颜色、字号、间距
- ❌ 每页自创布局，偏离 7 种母版
- ❌ 紫色系配色（#7C3AED / #8B5CF6 等 AI 高频色）
- ❌ 深色背景浅色大段文字（除非用户明确要求暗色模板）

━━━━━━━━━━━━━━━━━━━━━━━━━━
6. 输出物
━━━━━━━━━━━━━━━━━━━━━━━━━━
1. assets/theme.css —— 含全部设计令牌与 7 种版式样式，逐段注释
2. index.html —— 引入 Reveal.js CDN，依次演示 7 种版式
3. 使用说明（10 行以内）：如何新增一页、允许改哪些变量

━━━━━━━━━━━━━━━━━━━━━━━━━━
7. 交付前自检（逐条回答）
━━━━━━━━━━━━━━━━━━━━━━━━━━
□ 全片颜色是否只来自令牌表？
□ 全片字号是否只来自阶梯？
□ 每页是否都能归入 7 种版式之一？
□ 内容是否顶对齐、边距统一？
□ 去掉文字后，是否仍像一份 PPT 而不是一个网页？
```

## 二、续页提示词（模板已有，让 AI 往里加页时使用）

> 这条很关键——生成新内容时最容易“跑味”，必须单独约束。

```text
基于现有 Reveal.js 模板新增幻灯片内容。硬性规则：
1. 只允许使用 assets/theme.css 中已定义的 CSS 变量和 7 种版式
   （layout-cover/section/list/two-col/figure/quote/end），
   禁止新增任何 class、任何颜色、任何字号、任何内联样式。
2. 每页内容遵循版式规范：标题左上加粗，正文顶对齐，
   页码自动生成规则不变。
3. 一页只讲一件事；要点不超过 6 条，每条不超过 2 行；
   超出就拆页，而不是缩小字号。
4. 内容语气：陈述事实，不写"接下来让我们看看""值得注意的是"
   之类的 AI 腔过渡语；不使用 emoji。
5. 图片/表格出现时必须套用 layout-figure 版式。
```

## 三、定制参数速查

| 参数 | 说明 | 示例 |
|---|---|---|
| 【主色】 | 模板唯一强调色 | Office 蓝 `#4472C4` / 深红 `#C00000` / 墨绿 `#2E7D32` |
| 【机构名】 | 页脚左侧文字 | 校名 / 课程名 |
| transition | 换页动画 | `slide`（最像 PPT）/ `none`（完全像） |

**选主色的建议**：PowerPoint 官方主题几乎都是"白底 + 一个饱和适中的主题色 + 深灰正文"。别选紫色系（AI 生成物高频色），别选荧光色。数学课件推荐 Office 蓝 `#4472C4` 或深红 `#C00000`。

**字体说明**：微软雅黑 + Calibri 是最"PowerPoint"的组合；如需更现代可换"等线 Light"做封面大标题，但正文保持微软雅黑。

**进阶（LaTeX 公式）**：如需数学公式，在主提示词第 3 节追加——

```text
- 引入 KaTeX（或 MathJax）渲染 LaTeX 公式，公式字号与正文一致（var(--fs-body)），
  公式颜色继承 var(--ppt-text)，禁止给公式加背景框或特殊颜色。
```

Reveal.js 对 KaTeX 有官方插件，公式渲染后和 PPT 里的公式对象观感一致。

## 四、可选加强：提供参考截图

如果手头有目标 PPT（比如学校统一模板），把截图一起喂给 AI，并在主提示词末尾追加：

```text
附图是目标 PowerPoint 模板的截图，请从中提取：
1. 主色/强调色（给出具体 hex 值）
2. 字号比例关系
3. 标题位置与装饰元素
提取后写入设计令牌表，再开始生成。提取结果先展示给我确认。
```

"先展示提取结果再生成"这一步能有效防止 AI 对着截图自由发挥。

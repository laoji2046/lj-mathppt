### 2. Markdown 源码面板两处 Bug
- `$$...$$` 只写了一半（少一个 `$`）时整块公式被丢弃 → `mdDeck.ts` 在块尾兜底：未闭合也把已收集内容作为公式保留（去掉多余的行尾 `$`）。

- **发现并修复 mdDeck 里 3 个丢失反斜杠的正则**（历史编辑事故）：`# 标题` / `Note:` / `![图](路径)` 之前根本没生效。

### 3. 公式 / 混排「只缩小不放大」
- 根因：`fitMath` / `fitContent` / `fitMixed` 用 `min(框宽/内容宽, 框高/内容高, 4)` 缩放 → 模板里的整页宽元素框把短公式放大到 4 倍（32px 字号渲染成 ~128px），与正文严重不成比例。
- 统一改为上限 1（只缩小不放大，装不下才缩）：公式大小由「字号」决定。
- 改动点：`MathElement.vue`（render+ResizeObserver）、`RichTextElement.vue`、`renderer.ts`（导出 PDF/PNG/HTML/放映/缩略图，与画布保持一致）。
- 混排额外修：内容块（fit-content）水平位置改为跟随「对齐」属性 —— 以前左对齐的正文块被强行居中，看着像被缩进。

### 4. 高中数学例题模板全部改用混排公式（8 套）
- `src/templates/mathAppletTemplates.ts` 重写：新增 `mix()` 混排工厂 + `leftCol()` 左栏游标（例题卡/分析/关键公式/解答/结论 依次下排，卡高按**估算排版行数**自适应）。
- 例题/分析/解答/结论 = richtex（正文 + `$...$` 内联公式）；关键推导式、右侧「关键公式卡」仍是 math 元素。
- 裸文本 `a x² − 2a x + 1` 之类改成 `$f(x)=ax^{2}-2ax+1$`；双击整块即可再编辑（源码 + 实时预览）。
- 自动化校验（esbuild 打包模板 + node 脚本）：扁平数组 / id 唯一 / 不越界 / 文字元素不重叠 / `$` 成对 / 花括号与 `\left\right` 配对 / 只用已知 LaTeX 命令 / 左栏底边 < 980，8 套全通过。

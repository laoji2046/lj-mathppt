## 应用研究：LJ-MathSlides（vue-app）

- 项目：`C:\Users\老冀\Desktop\vue-app`，Vue 3 + TS + Pinia + Vite，桌面端 Tauri 2（NSIS 安装包）。
- 定位：高中数学幻灯片编辑器，核心架构是「场景图驱动」——`Deck → Slide → SlideElement[]`（15 种元素类型），区别于原版（lj-ppt，HTML 字符串 + Reveal 即编辑器）。README.md 是权威文档，非常详尽。
- 关键结构：
  - `src/types/index.ts`（791 行）：全部元素类型 + 工厂 `createElement` + 预设表（字体/阴影/主题/艺术字/数学图形等）。
  - `src/stores/deck.ts`（761 行）：唯一数据源，选中/组合/对齐/分布/图层/快照式撤销重做（100 条）/localStorage 自动保存 + 版本历史（20 个）/旧存档向后兼容补字段。
  - `src/components/PropertyPanel.vue` 最大（1182 行）；`EditorCanvas.vue` 负责拖拽调度、框选、平移、吸附。
  - `src/reveal/renderer.ts`（831 行）：场景图 → Reveal 演示页；演示用应用内 iframe 覆盖层（Tauri 不能 window.open）。
  - 模板库：`src/templates/`（mathTemplates 单页版式 / mathBundles 整套讲座 / proTemplates PPT 风母版 / formulaLibrary 按章节公式库）。
  - 离线引擎内嵌 `public/`：geogebra 5.0（~97MB）、mathjax、desmos、revealjs、pdfjs。
- Tauri 后端命令：`app_dir` / `list_dir` / `export_json`（base64 写盘防路径穿越）。
- 本机开发注意：npm install 会被 safe-delete 钩子拖死，直接调 `node node_modules/vite/bin/vite.js`；tauri build 前手动清 dist/，先关掉原应用进程。

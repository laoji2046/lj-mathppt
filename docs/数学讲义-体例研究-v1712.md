## 1. 常见栏目名称与顺序

### 1.1 四种课型的「栏目链条」

综合 A/B/C 级来源与 D 级共识，四种课型的主链条如下（→ 表示页面上的先后顺序）：

#### （1）新授课（同步）讲义 / 学案

```
【课前环节】
课题 + 课时 + 班级/姓名/日期（页眉）
学习目标 →（学习重难点）→ 知识链接 / 课前小测 / 复习回顾
【课中环节】
情境导入 → 知识梳理（新知生成，含留空填空）→ 典例精讲（例1、例2…）
→ 变式训练（变式1-1…）→ 方法归纳 / 规律小结 → 当堂检测（随堂练习）
【课后环节】
课堂小结（知识网络，留空）→ 课后作业（分层：基础/提升）→（学习反思）
```

#### （2）一轮复习讲义（按教材顺序、逐章逐节）

```
课标要求 / 考情分析（近5年考点分布）→ 知识梳理（知识清单 / 知识网络，大量留空）
→ 考点突破（考点1、考点2…，每考点配 典例 + 变式）→ 方法技巧归纳 / 易错提醒
→ 当堂检测（限时训练）→ 课时作业（分层作业：A基础 B提升 C拓展）
```

#### （3）二轮专题讲义（打破教材顺序，按题型/方法/思想组织）

**真实校本案例（B 级）**：南京市临江高级中学一节高三《综合训练讲评》公开课，被听课组总结为「**考题再现 → 高考链接 → 变式拓展 → 当堂训练 → 课后作业**」的**五层分层选题体系**，并形成「**母题精讲 → 变式迁移 → 即时刷题**」的复习闭环；载体是「以高考真题分层微专题」，每个母题配套**同源变式**（如「单调性」真题后紧跟「值域为 R」变式，奇偶性真题配套 3 道同源改编变式）。
来源：<http://ljgjzx.jnjy.net.cn/html/202606/NewShow-0765ab2ef5.html>

由此归纳二轮专题通用链条：

```
专题名 + 课时 → 真题导入 / 考题再现 → 高考链接（命题角度、分值、位置）
→ 必备知识 / 方法提炼（思维导图式，非教材复述）
→ 母题精讲（典型例题，含思路分析与规范解答）
→ 同源变式（变式拓展，改条件/改结论/改设问）→ 当堂训练（限时）
→ 课后作业（专题检测 / 组合训练）
```

#### （4）习题课 / 讲评课讲义

**习题课**（一题多用、以题带法）：

```
学习目标（方法目标）→ 题组呈现（例1…/题组一…）→ 一题多解 / 一题多变 / 多题一法
→ 方法归纳（通性通法）→ 变式训练 → 巩固练习 → 小结
```

**讲评课**（试卷/作业讲评）——陕西教育新闻网公开的教学设计给出**真实可复制的流程（B 级）**：
「课前准备 → **"望"卷明得失**（学生自诊，填表：每题知识点、应得分、实得分）→ **"闻"卷归错因**（限时 5 分钟自主归因）→ **"问"卷议盲区**（结合阅卷数据锁定共性错误与错误率最高的两道题）→ **"切"卷解难题**（出示错例 → 讨论错因 → 真题再现 → **当堂变式训练** → 限时独立完成 → 学生讲评反馈 → 师生共结方法）→ **总结反思促提升**（完善反思表、定改进措施）→ 布置作业（完善错题本 + 针对性训练）」
来源：<http://www.sxjybk.com/2025/1014/123589.html>

归纳讲评课讲义链条：

```
考情数据（分数段、得分率、班级均分）→ 学生自我诊断表（题号/知识点/应得分/实得分/错因）
→ 错因归类（知识性 / 方法性 / 规范性 / 审题性）→ 典型错题精讲（错例展示 + 正确解答 + 评分点）
→ 变式训练 / 真题再现 → 当堂订正（限时）→ 补偿训练（同源题）→ 错题本 + 反思
```

### 1.3 一线真实栏目名（B 级，可作为「落地写法」参照）

江苏省仪征中学教务处公开的《第十三周导学案检查记录》（2024-2025 学年第一学期）中，**实际出现的栏目名**包括：
【导学】【学习内容】【导思】【核心归纳】【课前预习】【必备知识】【基础训练】【提升性练习】【补充练习】【课时作业】【学科作业】【微专题】【周末试卷讲评】
来源：<http://www.jssyzzx.cn/view-58507.html>

同一份检查记录还给出了**真实的质量红线**（非常有参考价值，属于教研组"真在管什么"）：
- 导学案与课时作业要**查重**，需有「**创新比例**」；
- 序号标点必须统一（不能有时 `1.`、有时 `1、`）；同类句子句末符号要一致；
- 表格应居中；题号必须连续（有一处「第 11 题题号应改为 9」）；
- **分层要用星号标注**（原批评：「课时作业没有标注星号，不能体现分层教学的思想」）；
- **与新高考方向不符的题要删**（原批评：《数列的通项》基础训练中「只需简单赋值就能解决」的第 1、2 题应删除，建议换成用归纳法解决周期数列的题目）；
- **该留白的地方要留白**（原建议：微专题「必备知识」环节可适当留白，给学生归纳和整理的空间）；
- **课后作业题号后不标分值**（原整改项：删除「课后作业选择题题号后面的分值」）。

> **E｜个人归纳**：这说明高中一线对讲义的关注点在「查重与创新、编号与标点的一致性、分层可视化（星号）、留白、与新高考题型趋势一致」，而不是花哨的视觉设计。做模板时应把这些做成**默认规则**而非可选装饰。

## 2. 学生版 / 教师版（答案版）规则

### 2.1 学生版留空 vs 保留

| 内容块 | 学生版处理 | 依据 |
|---|---|---|
| 学习目标、重难点、学法指导 | **完整保留**（这是"导学"的核心） | 30edu：学习目标具有导向、激励、调控功能，且要与当堂检测对应 |
| 知识梳理 / 知识清单 | **结论、公式、定理、表格内容留空**，只留框架与提示语 | 30edu：学习小结「具体的知识点要尽可能留空由学生来填」 |
| 例题的题干、图形 | **完整保留**（题目是学习的载体） | D｜通行做法 |
| 例题的解析与答案 | **留空**（留出书写区），或只给「思路点拨」一行 | D｜通行做法 |
| 变式训练的答案 | **留空** | D｜通行做法 |
| 当堂检测 / 作业的答案 | **留空**（答案移入教师版或书后答案册） | D｜通行做法 |
| 方法归纳 / 规律小结 | **留空**（表格或填空式） | 仪征中学检查记录：「必备知识环节可适当留白，给学生归纳和整理的空间」 |
| 知识点对应页码、教材链接 | 保留（便于预习定位） | 仪征中学检查记录提到政治学科「只列出了需要掌握的知识点以及对应的页码」，被建议再加解释提示 |

### 2.2 教师版额外包含什么

**D｜多来源一致 + E｜个人归纳**，教师版（答案版/解析版）除学生版全部内容外，通常增加：

1. **答案解析**：选择题选项分析（为何对、为何错）、填空题答案、解答题**规范解答过程**；
2. **一题多解**与**最优解法点评**（临江高中点评中提到「奇偶性真题配套 3 道同源改编变式」「改变条件实现一个考点多角度深挖」）；
3. **易错点 / 易混点提醒**（临江高中点评：分段函数聚焦「周期性推导、分段衔接点取值、区间单调性判断」三大易错点）；
4. **评分标准 / 给分点**（对应 2024 新课标卷「增加过程性给分」的改革方向，见第 6 节）；
5. **教学建议 / 设计意图**（该栏目为何这样设计、时间分配建议）；
6. **变式的出处与改编说明**（真题来源年份、卷别）；
7. **作业答案与分层说明**（哪几题是 A 层必做、哪几题是 C 层选做）。

### 2.3 页面上如何区分（实操层）

| 区分方式 | 具体做法 | 证据/说明 |
|---|---|---|
| 文件名后缀 | `…_学生版` / `…_教师版`；商业讲义多用 `原卷版 + 解析版`、`（教师版+学生版）` | C 级：21世纪教育网资源标题「抛物线及其标准方程 讲义（教师版+学生版）」；51教学资源「（讲义+精练）（学生版+解析）」 |
| 页眉/页脚水印 | 页眉加「教师版（含答案）」「学生版」，或页面斜向水印 | D｜通行做法 |
| 答案位置 | ① 答案紧跟题目（教师版）；② 答案统一置后（学生版配答案册）；③ 答案"隐藏"（白色字/文本框覆盖，打印可见或不可见） | CTAN exam-zh 包页明确提供 **answer control（答案控制）** 与 **draft mode（草稿模式）**，正是这一需求的工具化实现 |
| 留白量 | 学生版按「书写行数」留白；教师版不留白、直接排解析 | D｜通行做法 |

**工具化证据（A 级）**：CTAN `exam-zh` 包官方描述：
> "exam-zh is a LaTeX class and a set of packages for creating **Chinese exam papers**. It provides various question types (**multiple choice, fill-in-the-blank, problem solving**), **answer control**, **draft mode**, and more. Written with expl3 and requires XeLaTeX."
来源：<https://ctan.org/pkg/exam-zh>
版本 0.3.6（2026-08-01），仓库 <https://github.com/xkwxdyy/exam-zh>，文档含 README.md、使用示例两份、`exam-zh-doc.pdf`，许可证 LPPL 1.3c，作者 Lijun Guo、Kangwei Xia，收录于 TeX Live / MiKTeX。

> **E｜个人归纳**：「answer control + draft mode」是讲义双版本的技术归纳——一套源文件，通过开关产出学生版/教师版；这与国内教研组「一份学案出两版」的诉求完全同构，可直接借用其设计思想（答案环境、留白环境、草稿模式）。

## 3. 教材自带栏目（人教A版 2019）及定位

### 3.1 人教A版栏目体系

**A 级来源**：人民教育出版社高中数学 2019 年教材培训专题页，列出必修各章及主讲人。
来源：<https://www.pep.com.cn/xw/zt/px/2019/shuxue/>

**B 级来源**：陕西教育新闻网《精准把握教材 用心设计教学》（袁芹芹），明确指出人教A版教科书的栏目设计意图：
> 「人教A版教科书通过合理设置（如**观察、思考、探究、归纳整理**等具体栏目），让学生真正投入到探索数学知识的发生、发展历程中……体现数学知识的基本形成过程：**问题→数学概念→数学性质或规律→解决实际问题**。」
> 并以「等式性质与不等式性质」为例：先设「**思考**」栏目（梳理等式基本性质、归纳方法），再通过「**探究**」栏目让学生「由等式的基本性质类比猜想不等式的基本性质」并加以证明。
来源：<http://www.sxjybk.com/2023/0109/51798.html>

**A/B 级佐证**：「拓广探索」是新人教A版的独立栏目层级——《中小学数学（高中版）》2023 年 03 期《高考题的摇篮——新人教A版之"拓广探索"》、2024 年 09 期《对新教材"拓广探索"题目的探究与思考》。
来源：<https://www.cnki.com.cn/Article/CJFDTotal-HZXG202303004.htm>、<https://wap-cnki-net-443.webvpn.imac.edu.cn/touch/web/Journal/Article/HZXG202409006.html>

### 3.2 栏目定位表

| 栏目 | 位置 | 定位（依据见上） | 讲义中的对应处理（E） |
|---|---|---|---|
| **观察** | 节内 | 提供直观情境/图形，引出问题 | 转为「情境导入」「问题串」 |
| **思考** | 节内 | 引导抽象、归纳、类比，指向概念本质 | 转为「思考1/思考2」留空提问，不要直接给答案 |
| **探究** | 节内 | 让学生自主/合作推导性质与规律 | 转为「探究活动」+ 留白 + 结论填空 |
| **归纳** | 节内 | 提炼结论、形成"一般观念" | 转为「知识梳理」结论框（学生版留空） |
| **练习** | 节内（例题后） | 即时巩固，直接对应本节例习题，量少 | 转为「当堂检测」的主干选题池 |

## 4. 版式细节

### 4.1 一份真实的学校「学案格式标准」（B/C 级）

哈尔滨市十三中学数学导学案（必修1）学案样板模式，文档摘要给出：
- **页面设置**：纸张 **B5，长 25.7 cm，宽 18.2 cm**；页边距**上下 2.54 cm、左右 3.17 cm**；
- **页眉页脚**：按示例设置，须**写清楚归属第几册书**；
- **页码**：居中插入页码。
来源：<https://www.renrendoc.com/paper/105260372.html>（文档摘要，页面正文为付费预览，未逐字核验全文）

> **E｜个人归纳**：B5 + 上下 2.54/左右 3.17 是 Word 中文文档的经典默认值（1 英寸/1.25 英寸），说明一线讲义大量沿用 Word 默认页面，**不追求特殊开本**。若做打印模板，A4 或 B5 单栏是安全区。

### 4.2 数学试卷/讲义排版规范（B 级，WPS 官方社区教程，可逐条落地）

来源：<https://bbs.wps.cn/topic/19923>《【WPS操作技巧】一种比较常用的数学试卷排版方案》

| 元素 | 规范 |
|---|---|
| 大标题 | **宋体、三号、加粗、居中**，标题后跟考试/使用日期；英文字体 Times New Roman |
| 小标题 | **黑体、五号、常规、左对齐**，**括号内标明分值和总分** |
| 正文中文 | **宋体、五号、常规、两端对齐** |
| 正文英文/符号 | Times New Roman 五号；**未知量倾斜、单位常规、大写字母倾斜、数字常规** |
| 页面布局 | 首选 **B4 横向，页边距上下左右 1.27 cm，分 2 栏**；或 A3 横向、页边距尽量小；或 A4 纵向排版后打印拼版 |
| 段落 | **不设首行缩进**，**行距 1.5 倍** |
| 选择题选项 | 用**制表位**对齐（保证 A/B/C/D 竖直对齐） |
| 填空题留空 | 两种做法：① 直接输入下划线（英文状态下 Shift + `-`）并调整长度；② **插入表格 → 去边框 → 设下框线**（好处：可在下框线上方单元格直接填答案，不必给文本加下划线） |
| 答题卡 | 【插入】→【表格】，设为**两行 n 列**：第一行题号、第二行学生填选项 |
| 公式 | 不建议用 WPS 自带公式（字体 Cambria Math 不便修改）；建议统一用「插入新公式」 |

> **D｜多来源一致**：五号（10.5pt）正文 + 1.5 倍行距 + 黑体小标题 + 无首行缩进，是中学数学讲义的**事实标准**；与论文/公文（小四、固定值 20 磅、首行缩进 2 字符）明显不同——**讲义属于"工作文档"，不是"正式出版物"**。

### 4.3 单栏 vs 双栏

| 场景 | 建议 | 依据 |
|---|---|---|
| 学生用讲义/学案（需要书写空间） | **单栏**为主；知识点填空、解答题下方留白 | 仪征中学检查记录强调留白；30edu 强调「容量以学生预习讨论合作时间不超过 30 分钟为宜」 |
| 试卷/限时训练/当堂检测 | **双栏**（B4 横向分 2 栏） | WPS 教程原文 |
| 教师版 | 可单栏密排（无书写需求），也可双栏省纸 | E｜个人归纳 |

### 4.4 页眉页脚

- **页眉**：讲义名称/册次归属 + 章节（学校格式标准要求「写清楚归属第几册书」）；教师版另加「教师版（含答案）」标识。
- **页脚**：**居中页码**（学校格式标准明确要求）。
- **姓名/班级/日期/节次**：常见两种位置——① 页眉右侧「班级：____ 姓名：____ 学号：____」；② 课题下方一行「班级____ 姓名____ 日期____」。
  **D｜多来源一致**；本次检索**未取得**规定"必须放在页眉/页脚哪一侧"的权威原文，学校间差异较大。

### 4.5 编号规则

| 对象 | 通行写法 | 依据 |
|---|---|---|
| 例题 | **例1、例2**…（章内连续编号） | D｜多来源一致；51教学资源「8.3导思例1选肢排列」 |
| 变式 | **变式1-1、变式1-2**（母题号-变式号），或「变式1」 | D｜多来源一致；临江高中「每个母题配套同源变式」 |
| 练习/检测 | **练习1、练习2** / **1. 2. 3.** / **当堂检测 1~5** | D｜多来源一致 |
| 作业 | **课时作业**独立编号，或接续练习编号 | 仪征中学「导学案 + 课时作业」；检查记录中有「题号应改为 9」的连续性问题 |
| 编号符号 | **同一文档内必须统一**（`1.` 与 `1、` 不能混用；同一层级子项符号一致） | **B 级原文**：仪征中学检查记录把「数字序号后标点不统一」列为**必须整改**问题 |
| 页码范围 | 页脚居中页码；长讲义建议「第 X 页 共 Y 页」 | E｜个人归纳 |

### 4.6 分值标注

- **试卷/检测**：小标题后**括号标注分值与总分**（WPS 教程原文，如「二、填空题（每题 5 分，共 15 分）」）。
- **课后作业**：**不标分值**（仪征中学检查记录明确把「课后作业选择题题号后面的分值」列为**应删除**项）。
- **解答题**：教师版建议标出**过程性给分点**（对应 2024 新课标卷"增加过程性给分"的官方表述）。

### 4.7 图形与公式

| 项 | 规范 |
|---|---|
| 图形位置 | 紧随题干或题干右侧；题图尽量与题干同页，避免跨页割裂 |
| 图号引用 | 正文统一用「**如图1**」「**图1**」；一图一编号；图形下方不重复写标题（讲义从简） |
| 图形工具 | 优先矢量（几何画板/GeoGebra 导出 EMF/SVG），避免低分辨率截图 |
| 行内公式 | 与文字同基线，如 `$f(x)=x^2$`；行内分式建议改用 `a/b` 或 `\frac` 缩小形式 |
| 行间公式 | 居中或缩进占一行；**讲义正文一般不编号**，仅在"公式需要被引用"（如"由公式(1)"）时用 `(1)` 右对齐编号 |
| 公式工具 | LaTeX（exam-zh / ctex）或 Word「插入新公式」；同一文档**不要混用两套公式引擎**（WPS 教程亦提示自带公式字体不便修改） |

## 6. 新高考题型结构（2024 起新课标卷）

### 6.1 官方权威结构（A 级）

**来源：教育部教育考试院《优化试卷结构设计 突出思维能力考查——2024年高考数学全国卷试题评析》（原载《中国考试》）**
转载页：<http://jky.sneducloud.com/webArticleAction/toNewsInformPage.jhtml?uuid=6568730387d8455e9f85>

**原文要点（逐条）**：
1. **题量**：2024 年命制全国甲卷文/理科、新课标Ⅰ卷、新课标Ⅱ卷共 4 套。新课标卷「多选题、填空题和解答题各减少 1 道题，**全卷由过去的 22 道题减少到 19 道题**」。
2. **分值**：「多选题由**每题 5 分增加到 6 分**，**解答题总分由 70 分增加到 77 分**」。
3. **多选题给分改革**：「由过去的答对一个选项给 2 分，变为**部分答对得部分分数**，有两个正确选项的**仅选其中一个给 3 分**；有三个正确选项的**仅选其中一个给 2 分，仅选其中两个给 4 分**」。
4. **压轴题**：「解答题的两个压轴题难度与以往相比有所增加，而且**分值由 12 分增加到 17 分**」。
5. **创新题**：新课标Ⅰ卷第 19 题「以等差数列为知识背景，创新设问方式，**设置数学新定义**……以**可分数列**的新定义为中介……**三个设问层层递进**」；新课标Ⅱ卷第 19 题「以学生熟悉的双曲线为知识素材……形成**一族点列**……**分层设问，环环相扣**」，体现「**多想少算**」。
6. **命题导向**：反套路、反刷题；「不考死记硬背、不出偏题怪题」；「**增加基础题比例、降低初始题起点**」；「合理控制试题的计算量……增加思维量」。

### 6.2 分值与题量明细（A 级官方 + B 级地方教研复核）

**来源（B 级复核）**：鸡西教育云《从2024年高考数学试题分值的变化看改革》
<https://edu.jixi.gov.cn/Article/47689.html>
原文：「单选题保持 **8** 道不变，多选题减少到 **3** 道，填空题减少到 **3** 道，解答题减少到 **5** 道。总分值 **150** 分维持不变，选择题和填空题的总分值由原来的 **80 分调整为 73 分**，解答题的总分值由 **70 分增加到 77 分**，多选题每题的分值由 **5 分调整至 6 分**，解答题的分值分布也发生了变化，**前三题分别为 13 分、15 分、15 分，后两题均为 17 分**。」

**交叉验算（E，算术自检）**：
- 选填：8×5 + 3×6 + 3×5 = 40 + 18 + 15 = **73 分** ✔ 与官方"选填 73 分"一致
- 解答：13 + 15 + 15 + 17 + 17 = **77 分** ✔ 与官方"解答题 77 分"一致
- 合计 73 + 77 = **150 分** ✔

| 题型 | 题量 | 每题分值 | 小计 |
|---|---|---|---|
| 单项选择 | 8 | 5 | 40 |
| 多项选择 | 3 | 6 | 18 |
| 填空 | 3 | 5 | 15 |
| 解答 | 5 | 13 / 15 / 15 / 17 / 17 | 77 |
| **合计** | **19** | — | **150** |

同一来源还给出：使用新课标卷的省份包括辽宁、江苏、广东、重庆、海南、湖北、湖南、山西、山东等；新课标Ⅰ卷函数与导数板块约占 38 分、Ⅱ卷约 31 分，「考点不再具有规律性」。

### 6.3 创新题的位置与特点（A 级）

| 特征 | 内容 |
|---|---|
| 位置 | **压轴位置（第 19 题，17 分）** 是"新定义/新情境"的主战场；新课标Ⅰ卷（可分数列）与Ⅱ卷（双曲线点列）均在此 |
| 形式 | **数学新定义**（在考场上现学现用）、**多问递进**（第(1)问入口低、第(3)问拔高）、**新情境**（数列结合概率、解析几何结合点列构造） |
| 设问 | 「三个设问层层递进……使得每个学生都能有所收获」——**低起点、高落点** |
| 结构不良问题 | 本次检索**未取得权威文件对"结构不良问题"在 2024 新课标卷中的位置/分值的直接规定**；仅检索到二轮复习资料中「结构不良题」作为专题存在（如 <https://zujuan.xkw.com/thematiclist/11pt5544ct17208n533231.html>）。**建议按"存在、作为创新题的一个亚类、多见于中后段解答题或选择填空压轴"处理，并标注为待核验。** |

### 6.4 对讲义栏目设计的直接含义（E｜个人归纳）

1. **多选题必须单列训练栏目**：因为"部分对给部分分"是新规则，讲义要能标出"漏选得 X 分 / 错选 0 分"的**评分细则**，并训练"不确定时只选最有把握的选项"的策略。
2. **填空题题量降到 3 题、分值提高（每题 5 分）**：讲义中"当堂检测"的填空不宜再堆量，应**精选、高区分度**。
3. **解答题分值梯度（13/15/15/17/17）**：课后作业/专题检测的**分值配置应复刻这一梯度**，让学生建立"分值—难度—时间"的映射感。
4. **压轴题 17 分 + 多问递进**：讲义应设「**压轴题分步得分训练**」栏目，第(1)问必做、第(2)问争取、第(3)问选做，强制学生练习"部分完成"。
5. **反套路**：仪征中学检查记录中"删除只需简单赋值就能解决的题"的整改意见，与官方"反机械刷题"导向**完全一致**——模板里应有「**本题思维量自检**」的钩子（例如备注栏要求写出"本题考查的思维方法"）。
6. **考试时间 120 分钟 / 19 题**：当堂检测与限时训练的**题量—时间比**建议按 19 题:120 分钟折算（约 6.3 分钟/题，压轴题需 20 分钟以上）。

## 8. 落地清单（Cheat Sheet）

**结构**
- [ ] 目标 3~4 条，动词可检测，与当堂检测一一对应

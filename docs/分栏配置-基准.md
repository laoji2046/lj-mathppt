## ❌ 已知坏法（别再用）

| 坏法 | 后果 |
|---|---|
| **一栏也套 column-fill:auto + 固定高度** ✗ | 内容超高度时多栏容器**继续开新栏** → 选一栏却挤出第二栏（v1317 病根）|
| **balance + 固定高度** ✗ | balance 需要高度自适应，给了高度等于 auto，等高失效 |
| **打印页 margin:auto 居中** ✗ | 打印时 body 宽≠纸张宽 → 整页右偏、左边被切（v1315）|
| **white-space:normal !important 打在 mjx-math 上** ✗ | 破坏 MathJax 内部排版 |
| **break-inside:avoid 同时写在两处** ✗ | 特异性相同靠顺序决胜，容易翻车 |
| **block 整块原子搬运** ✗ | 长题放不下就整块推走 → 页面留大空档 |

# 使用说明 · 圆锥曲线组合图形

> 面向使用：**圆锥曲线 + 直线/线段 + 标注点**，全部由参数驱动，画完后还能在画布上直接拖。
> 入口：工具栏 **数学图形 → 圆锥曲线**（共 19 个）
> 工程实现见 `src/composables/mathPlot.ts`；内部诊断/调参记录见 `docs/矢量描摹-诊断.md`。

## 一、五个「自定义」图形

| 卡片 | 可调参数 | 说明 |
|---|---|---|
| **自定义圆 + 直线/线段** | 圆心 x、圆心 y、半径 r | 取景跟着圆心走 |
| **自定义椭圆 + 直线/线段** | a（半长轴）、b（半短轴） | 焦点在 x 轴 |
| **自定义椭圆·长轴在 y 轴 + 直线/线段** | a、b | 同上，转 90° |
| **自定义双曲线 + 直线/线段** | a（实半轴）、b（虚半轴） | 取景按支线落点适配（见下）|
| **自定义抛物线 + 直线/线段** | p（焦准距）、开口（1右 2上 3左 4下）| 取景按开口方向整体偏移 |

这五个**共用同一套**「直线 / 线段 / 标注点 / 颜色 / 拖动」能力。

## 二、直线与线段（最多 4 条）

| 面板项 | 含义 |
|---|---|
| **直线 / 线段条数** | 0–4（默认 0 = 不画，所以老图形完全不变）|
| **线N 的那个矩形框** | **这条线的所有属性都在这一个框里、一行排开**：`k` `m` `起x` `终x` `虚线` `色` |
| ↳ k / m | 直线 y = kx + m |
| ↳ 起x / 终x | 两点**相同** = 画**整条直线**（自动铺满图形框）；**不同** = 画**线段** |
| ↳ 虚线 | 这条线自己用虚线（勾选框）|
| ↳ 色 | 这条线自己的颜色（**圆点**，点开是同一套主题色面板）|
| **线段端点圆点** | 勾选框：线段两端是否画小圆点（默认画）|

- **直接拖端点**：单击选中图形 → 线上会出现**绿色方块**手柄 → 拖动即可改这条线。
  拖一个端点时**另一端固定**，程序反算 k、m（线段还会同步改起终点）。
  端点可以**拖到图形框外** —— 线会一直延伸到框边，不会"被一个矩形框住"。
- **竖直线画不了** —— y = kx + m 表示不了竖直方向；需要竖线时用「自定义抛物线」的准线开关，
  或直接用现成的「椭圆（焦点·准线）」等图元。

## 三、标注点（最多 6 个，圆点 + 名称）

| 面板项 | 含义 |
|---|---|
| **标注点的个数** | 0–6（默认 0）|
| **点N 的那个矩形框** | **这个点的属性都在一个框里、一行排开**：`x` `y` `大小` `色` |
| ↳ x / y | 图形坐标（不是像素）|
| ↳ 大小 | 圆点粗细，0.3–3，默认 1 |
| ↳ 色 | 单独给这个点上色（不设 = 跟线条颜色），**圆点**点开选色 |
| **点N 名称** | 文本框；支持下标写法 `A_1`、上标 `B^2`、撇 `A'`；留空则该点不标名字 |

- **直接拖点**：选中图形后，点上会出现**橙色圆形**手柄，拖动即可。
- 点的圆点带白色描边，压在曲线或虚线上也看得清。
- 改了颜色，**点的名字也跟着变色**（一眼能对上号）；改大小只影响这一个点。

### 一键求交点（推荐先用这个）

属性面板里的 **「求交点 → 生成标注点」**：自动算出**每条直线 / 线段**与这条圆锥曲线的交点，
直接生成标注点，名字默认 `P_1`、`P_2`…（可改名）。

**这些点是「活的」—— 钉在交点上，随直线自动变化：**

| 你做的事 | 交点会怎样 |
|---|---|
| 改 k、m，或拖直线端点 | **跟着动**（位置每次现算，不是存下来的死坐标）|
| 把线拖到离开曲线 | **自动隐藏**；线回来它们就回来 |
| **拖交点本身** | **以另一端为支点转动这条线**（同几何画板里拖弦的端点）：被拖的点顺着指针方向沿曲线走，另一端不动 |
| 手动改它的 x / y | **解除绑定**，变回普通点（此后不再随直线动）|

> ⚠ 拖交点时它**不会精确停在指针处** —— 交点必须落在圆锥曲线上，这是几何约束，不是 bug。
> 它会朝指针方向沿曲线走到最近的位置。

- 支持全部五类自定义图形，含抛物线的四个开口方向。
- **线段**只保留落在它起终点 x 之间的交点；**相切**只出一个点；重复的点会自动跳过（再点一次不会加一批重复的）。
- 一次最多 6 个（标注点上限）；先算出来的点不会被覆盖，新点接在后面。

## 四、显示开关（都在属性面板里）

| 勾选框 | 出现在 | 默认 |
|---|---|---|
| **显示 a、b 标注** | 两个自定义椭圆 | 开 |
| **显示准线** | 抛物线（x = −p/2）、椭圆（x = ±a²/c 或 y = ±a²/c）、双曲线（x = ±a²/c）| 抛物线 **开**；椭圆/双曲线 **关** |
| **显示渐近线** | 双曲线（y = ±(b/a)x）| 自定义双曲线 **关**；静态双曲线 **开** |
| **线段端点圆点** | 有线段时 | 开 |

> 默认值的原则是「**保持该图形原本的样子**」，所以老图形不会因为升级而变样。

## 五、颜色与虚实（都能各自单独控制）

| 控制项 | 影响范围 |
|---|---|
| 线条颜色 / 线宽（面板上方） | 元素整体（也是坐标轴、曲线的**默认色**）|
| **曲线颜色** | 圆锥曲线本身（含焦点、a、b 标注）|
| **坐标轴颜色** | **只**影响两条坐标轴 |
| **线N 的「色」圆点** | 每条线**各自**一个颜色（就在线N 那个矩形框里）|
| **点N 的「色」圆点** | 每个标注点**各自**一个颜色（就在点N 那个矩形框里）|
| **曲线用虚线** | 圆锥曲线本身 |
| **坐标轴用虚线** | 两条坐标轴 |
| **线N 用虚线** | 每条线**各自**（例如"虚线标交点、实线画图形"）|
| a、b 标注 / 准线 / 渐近线 / 线段端点圆点 / 显示弦长 | 勾选框 |

于是一张图上可以做到：**坐标轴一种颜色和虚实、曲线另一种、每条线又各不相同**。

> 选中**数学图形**时，属性面板不再显示「图形类型」那一大块（连同"线型"下拉）——
> 那是给形状/直线用的；数学图形自己的类型切换在「数学图形 → 图形」里。

## 六、几个典型做法

### 动点（在曲线上滑动）

按钮 **「＋ 在曲线上加动点」** → 新增一个**绑在曲线上**的点（名字默认 `M_1`）：

- 拖它**只会沿曲线滑动**，绝不会跑出曲线（把指针位置投影到曲线上离它最近的位置）
- 可以照常改名；也可以给它作切线

### 切线（随点自动转）

按钮 **「＋ 过标注点作切线」** → 新增一条线，并把它**绑成"最后一个落在曲线上的点"处的切线**：

- 那个点一动（动点滑动、交点移动），**切线自动跟着转** ✓
- ⚠ 竖直切线（椭圆 / 圆的左右顶点那种）用**很大的斜率**近似 —— 直线模型 y=kx+m 表示不了竖直
- 切线的 k、m 是**算出来的**：面板里那两行改了没用（要动就动切点）

### 显示弦长

勾上 **「显示弦长」**（默认关）→ 每条**与曲线有两个交点**的线，会在弦的中点标出长度（两位小数，如 `8.00`）。

## 几个典型做法（表）

| 想画 | 做法 |
|---|---|
| 椭圆 + 一条过焦点的弦 | 插「自定义椭圆」（a=4、b=3）→ 条数=1 → 调 k、m 让线穿过焦点；或**直接把端点拖到焦点上** |
| 抛物线与直线相交 | 插「自定义抛物线」→ 开口选 1（右）→ 条数=1 → 调 k、m → 点**「求交点 → 生成标注点」**，交点自动标好 |
| 双曲线与渐近线 | 插「自定义双曲线」→ 勾上**显示渐近线**（默认关）→ 再按需加直线 |
| 圆的切线 | 插「自定义圆」→ 条数=1 → 把线段起点/终点拖成切线 |

## 七、注意事项与已知限制

1. **参数面板只显示"用得上"的项**：条数设 0 时看不到 k/m/起终点，设 1 才出现第 1 条的 4 个参数 —— 这是有意的（否则近 20 个滑杆没法看）。
2. **半径 / a、b 决定的是"坐标系里的形状"**，元素的物理尺寸由**画布上的元素框**决定。
   半径调大时取景也会跟着放大，到某个程度曲线就顶满整个框了 —— 还想更大就**拖元素框的角**放大元素。
3. **双曲线的取景**是按"支线正好够到上下边"算的，所以支线与渐近线会**几乎同时到达框边**
   （早先版本会出现"支线是小短弧、渐近线却冲到框角"）。
4. **倾斜的椭圆 / 双曲线不支持** —— 模型是轴对齐的。矢量描摹遇到倾斜椭圆时会明确提示。
5. **拖动前必须先选中图形**（单击元素）。拖动时手柄会跟着指针走，松手后参数写回面板。
6. 这些图形是**矢量**的：导出 PDF / 演示时线条锐利，参数与颜色也都跟着走。
7. **想固定住图形，用「锁定位置」**：属性面板最上面「位置与尺寸」里有一个勾选框
   **锁定位置**（对所有元素都有效，文字、图片也一样）。勾上之后：
   - 画布上**拖不动、也缩放不了**（8 个缩放把手会隐藏），但**仍然可以选中**、照样能改属性；
   - 想再挪动，把勾去掉即可。
8. **参数面板现在"并行"显示**：点的 x / y / 大小 在同一行，直线的 k / m 在同一行、起 x / 终 x 在同一行
   —— 4 条线从 20 行压到 8 行，面板更短。

## 八、和「矢量描摹」的关系

描摹（图片转图形）得到的是**逐点还原**的线稿；这里是**参数化的标准图形**。
两者的桥：描摹弹窗里的 **「○ 拟合成标准椭圆」** —— 量出图里椭圆的形状，直接生成一个
「自定义椭圆」图元（a、b 可继续调）。

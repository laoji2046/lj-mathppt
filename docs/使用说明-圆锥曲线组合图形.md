# 使用说明 · 圆锥曲线组合图形

> 面向使用：**圆锥曲线 + 直线/线段 + 标注点**，全部由参数驱动，画完后还能在画布上直接拖。
> 入口：工具栏 **数学图形 → 圆锥曲线**（共 19 个）
> 工程实现见 `src/composables/mathPlot.ts`；内部诊断/调参记录见 `docs/矢量描摹-诊断.md`。

## 一、五个「自定义」图形

| 卡片 | 可调参数 | 说明 |
|---|---|---|
| **自定义圆 + 直线/线段** | 圆心 x、圆心 y、半径 r | 取景跟着圆心走 |
| **自定义椭圆 + 直线/线段** | a（半长轴）、b（半短轴） | 焦点在 x 轴 |
| **自定义椭圆·长轴在 y 轴 + 直线/线段** | a、b | 同上，转 90° |
| **自定义双曲线 + 直线/线段** | a（实半轴）、b（虚半轴） | 取景按支线落点适配（见下）|
| **自定义抛物线 + 直线/线段** | p（焦准距）、开口（1右 2上 3左 4下）| 取景按开口方向整体偏移 |

这五个**共用同一套**「直线 / 线段 / 标注点 / 颜色 / 拖动」能力。

## 二、直线与线段（最多 4 条）

| 面板项 | 含义 |
|---|---|
| **直线 / 线段条数** | 0–4（默认 0 = 不画，所以老图形完全不变）|
| **线N 斜率 k / 截距 m** | 直线 y = kx + m |
| **线N 起点 x / 终点 x** | 两点**相同** = 画**整条直线**（自动铺满图形框）；**不同** = 画**线段** |
| **线段端点圆点** | 勾选框：线段两端是否画小圆点（默认画）|

- **直接拖端点**：单击选中图形 → 线上会出现**绿色方块**手柄 → 拖动即可改这条线。
  拖一个端点时**另一端固定**，程序反算 k、m（线段还会同步改起终点）。
  端点可以**拖到图形框外** —— 线会一直延伸到框边，不会"被一个矩形框住"。
- **竖直线画不了** —— y = kx + m 表示不了竖直方向；需要竖线时用「自定义抛物线」的准线开关，
  或直接用现成的「椭圆（焦点·准线）」等图元。

## 三、标注点（最多 6 个，圆点 + 名称）

| 面板项 | 含义 |
|---|---|
| **标注点的个数** | 0–6（默认 0）|
| **点N 横坐标 x / 纵坐标 y** | 图形坐标（不是像素）|
| **点N 名称** | 文本框；支持下标写法 `A_1`、上标 `B^2`、撇 `A'`；留空则该点不标名字 |

- **直接拖点**：选中图形后，点上会出现**橙色圆形**手柄，拖动即可。
- 点的圆点带白色描边，压在曲线或虚线上也看得清。

## 四、显示开关（都在属性面板里）

| 勾选框 | 出现在 | 默认 |
|---|---|---|
| **显示 a、b 标注** | 两个自定义椭圆 | 开 |
| **显示准线** | 抛物线（x = −p/2）、椭圆（x = ±a²/c 或 y = ±a²/c）、双曲线（x = ±a²/c）| 抛物线 **开**；椭圆/双曲线 **关** |
| **显示渐近线** | 双曲线（y = ±(b/a)x）| 自定义双曲线 **关**；静态双曲线 **开** |
| **线段端点圆点** | 有线段时 | 开 |

> 默认值的原则是「**保持该图形原本的样子**」，所以老图形不会因为升级而变样。

## 五、颜色

- **椭圆（曲线）颜色**：只影响圆锥曲线本身（含焦点、a/b 标注）。
- **线1 / 线2 / … 颜色**：每条线**各自**一个颜色。
- **线条颜色**（面板上方）：坐标轴与整体主色。
- 一张图上可以做到：曲线一个色 + 每条线不同色 + 坐标轴另一种色。

## 六、几个典型做法

| 想画 | 做法 |
|---|---|
| 椭圆 + 一条过焦点的弦 | 插「自定义椭圆」（a=4、b=3）→ 条数=1 → 调 k、m 让线穿过焦点；或**直接把端点拖到焦点上** |
| 抛物线与直线相交 | 插「自定义抛物线」→ 开口选 1（右）→ 条数=1 → 调 k、m；交点用**标注点**标出来 |
| 双曲线与渐近线 | 插「自定义双曲线」→ 勾上**显示渐近线**（默认关）→ 再按需加直线 |
| 圆的切线 | 插「自定义圆」→ 条数=1 → 把线段起点/终点拖成切线 |

## 七、注意事项与已知限制

1. **参数面板只显示"用得上"的项**：条数设 0 时看不到 k/m/起终点，设 1 才出现第 1 条的 4 个参数 —— 这是有意的（否则近 20 个滑杆没法看）。
2. **半径 / a、b 决定的是"坐标系里的形状"**，元素的物理尺寸由**画布上的元素框**决定。
   半径调大时取景也会跟着放大，到某个程度曲线就顶满整个框了 —— 还想更大就**拖元素框的角**放大元素。
3. **双曲线的取景**是按"支线正好够到上下边"算的，所以支线与渐近线会**几乎同时到达框边**
   （早先版本会出现"支线是小短弧、渐近线却冲到框角"）。
4. **倾斜的椭圆 / 双曲线不支持** —— 模型是轴对齐的。矢量描摹遇到倾斜椭圆时会明确提示。
5. **拖动前必须先选中图形**（单击元素）。拖动时手柄会跟着指针走，松手后参数写回面板。
6. 这些图形是**矢量**的：导出 PDF / 演示时线条锐利，参数与颜色也都跟着走。

## 八、和「矢量描摹」的关系

描摹（图片转图形）得到的是**逐点还原**的线稿；这里是**参数化的标准图形**。
两者的桥：描摹弹窗里的 **「○ 拟合成标准椭圆」** —— 量出图里椭圆的形状，直接生成一个
「自定义椭圆」图元（a、b 可继续调）。

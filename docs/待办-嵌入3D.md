## 我已核对的现状（读代码得到，不是推测）

**嵌入元素 `EmbedElement.vue` 已经支持的能力**：

| kind | 渲染方式 |
|---|---|
| image | data URL ✓ |

| **html** | **dataBase64 → Blob → iframe ✓** |

**关键点**：

- iframe 的 sandbox 是 `allow-scripts allow-same-origin allow-forms allow-popups allow-downloads`

- iframe 的 `pointer-events: none` ✓ —— 这样点/拖任意处都能选中并移动整个元素 ✓

    public/three.min.js            ← 相对路径引用 ✓ Tauri 里能取到 ✓

    **懒加载**：只在真有 3D 嵌入时才加载 ✓ 不进启动包 ✓
    验收时要量：**启动时间与 exe 体积都要复测** ✓

# 题库 Markdown **规范格式**（唯一模板）

> 这份格式就是「试题库 → 导出 Markdown」导出的格式，也是「录入试题 → 导出规范 MD」写出的格式。
> **它与导入器双向对齐**：规范文件 → 导入 → 再导出，字段不丢（真机往返 47/47 验证过 ✓）。
> 需要别人（或 AI）给你出题时，把这份文档连同下面的模板一起发过去即可。

## 1. 一句话规则

**一道题 = 一段 YAML front-matter（`---` 包起来）+ 四个 `##` 小节**；一个文件里可以放**多道题**（导入侧按 front-matter 开头切块 ✓）。

## 2. 模板（照抄改内容即可）

```markdown
---
qid: 1
source: 2027届某市高三9月联考
number: '1'
type: choice
section: 函数与导数
year: 2027
level: 中档
difficulty: 0.65
updatedAt: '1789898188'
knowledge:
- 函数
- 基本初等函数
---

## 题目

已知函数 $f(x)=x^{2}+2x$，则 $f(1)=$（ ）

## 选项

A．1
B．2
C．3
D．4

## 答案

C

## 解析

因为 $f(1)=1+2=3$，故选 C.
```

## 3. 字段表（front-matter）

| 键 | 必填 | 说明 |
|---|---|---|
| `qid` | ✅ | 块的第一行必须是 `qid` / `source` / `number` 之一（切块靠它）。**导入时会重新编号**，这里写什么都行 |
| `source` | ✅ | 试卷名 / 来源（入库进 `paper`；「来源报告」按它统计成型率） |
| `number` | ✅ | **题面上的原始题号**（多卷合一时每卷各自从 1 开始）。它决定「卷尾答案区按题号配答案」能不能对上 ✓ |
| `type` | 可选 | `choice` 单选 / `multi` 多选 / `blank` 填空 / `answer` 解答（不写就按选项与内容推断） |
| `section` | 可选 | 六大板块之一（函数与导数 / 三角…）；不写会在库里归到「未归类」 |
| `year` | 可选 | 4 位年份（`0` 或省略 = 没年份） |
| `level` | 可选 | 中文档：基础 / 中档 / 拔高（**给人看的**，入库以 `difficulty` 为准） |
| `difficulty` | 可选 | **系数**：0.94 / 0.80 / 0.65 / 0.45 / 0.20 ↔ 难度档 1/2/3/4/5（这一列是入库依据 ✓） |
| `updatedAt` | 可选 | 秒级时间戳（字符串） |
| `knowledge` | 可选 | 知识点列表（`knowledge: []` 或 `- 逐条`） |

> 其它键也认：`paper`（=`source`）、`tags` / `ai_tags`（并入知识点）、`grade` / `semester`（地区/学期）。

## 4. 小节（正文）

| 小节 | 作用 |
|---|---|
| `## 题目` | 题干（**必填**）。公式用 `$…$` / `$$…$$`；插图写 `![图N](assets/xxx.jpg)` 或干脆写 `[图N]` 标记 |
| `## 选项` | 每题一行：`A．…`（全角点或半角点都认；也可写成 `A. …`） |
| `## 答案` | 选择/填空给答案本身；解答题可以整段给结论 |
| `## 解析` | 详解（可省） |

标题别名也认：`## 题干`、`## 详解`。

## 5. 怎么把**已有的一堆乱格式 md** 变规范

1. 打开「试题库 → **录入试题**」；
2. 左边粘贴/选择你的 md（AI 给的、别人发的、旧的都能试）→ 点「**按 Markdown 解析**」；
3. 在右边**校对表**里核对（题型 / 板块 / 年份 / 试卷名 / 答案都能就地改）；
4. 点工具栏「**导出规范 MD**」→ 选目录 → 得到一份**规范文件**；
5. 以后就拿这份文件当模板（再导入、发给别人、喂给 AI 都行 ✓）。

> 批量填来源：上面填「年份 / 试卷名」再点「批量填来源」，会套到所有勾选的题上 ✓

## 6. 我们**不做**的事（免得误会）

- **不猜**：题干对不上就不配答案、来源认不出就留空（只在确凿不成立时才清告警）；
- 规范文件里 `qid` 是**占位**：入库时按规则重新分配 `P-年份-序号`；
- 图片：规范文件里是相对路径 `assets/…`，导入时**不会**把图收回库（图随库走的是 base64/资源行，见方案 §22）。

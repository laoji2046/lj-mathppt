## 稳健定位（推荐做法）

1. **别用 `children.length === 0` 限死叶子** ✗ —— 按钮里有 svg 图标和计数 span，
   限死叶子会让「立体几何 16」这种标签永远匹配不上（实测踩过）。
2. 按文字找元素时，取**包含该文字且 innerText 最短**的那个（最内层）；
   再 `closest('.palette')` / 沿 `parentElement` 爬到 `position: fixed|absolute` 的浮层做裁剪。
3. **类名优先从源码读**：`Select-String -Path src\components\*.vue -Pattern '<div class="([a-z0-9-]+)"'`。

## 稳健定位（推荐做法）

1. **别用 `children.length === 0` 限死叶子** ✗ —— 按钮里有 svg 图标和计数 span，
   限死叶子会让「立体几何 16」这种标签永远匹配不上（实测踩过）。
2. 按文字找元素时，取**包含该文字且 innerText 最短**的那个（最内层）；
   再 `closest('.palette')` / 沿 `parentElement` 爬到 `position: fixed|absolute` 的浮层做裁剪。
3. **类名优先从源码读**：`Select-String -Path src\components\*.vue -Pattern '<div class="([a-z0-9-]+)"'`。

### ⚠ 五条血泪（同一天，同一个病根：从外部猜 DOM）

1. **猜类名** —— `.g3d` 而真名是 `.g3`（差一个字符，最难发现）
2. **定位器限死叶子** —— `children.length===0` 让「立体几何 16」这类带计数 span 的标签永远匹配不上
3. **用合成 `.click()`** —— 标签切不动；换**真实鼠标事件**（Input.dispatchMouseEvent）才成
4. **按文字定位** —— 命中错元素（工具栏别处也含「图片」二字）；该按 `title`
5. **`querySelector` 只取第一个匹配** —— 第一个常是隐藏元素（v-if 未渲染/零尺寸），于是返回 null

**结论：正确答案全在源码里，读一次源码的成本远低于试错五次。**

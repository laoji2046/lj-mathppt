# 试题库重设计（v1409 起）

> 起因：用户反馈「查询按分类不总能在左边栏看到题目」「有的题目被切成几道不同的题目」。
> 本文先给**实测证据**，再给**新设计**，最后是**分期实施**。

---

## 一、实测到的真问题（都有数据）

在打包 exe + 真实试卷 + 真实题库（169 道）上跑出来的：

| # | 现象 | 实测证据 | 根因 |
|---|---|---|---|
| 1 | **点板块筛不出题** | 169 道里，6 个板块按钮分别筛出 9 / 33 / 13 / 35 / 5 / 10 = **105 道**，**64 道（38%）无板块**，在任何板块下都看不到 | ① 归类是"关键词命中即返回"，**顺序敏感**（"已知函数 f(x)=sin2x…" 命中"函数"→ 判成函数与导数 ✗）；② 分类**只有 6 个板块**，缺数列/复数/不等式/计数原理；③ **没有"未分类"入口**，未归类的题只能靠"全部"看到 |
| 2 | **答案被当成题**（"题目被切成几道"） | 真卷正文 19 题，解析出 **24 题**，多出的 5 条是填空/解答的**答案**（如 `$\sqrt{6}$ 13. $\frac{\pi}{3}$ 14. 24`） | `parseQuestions` 里**先按小节标题切段、再剥"参考答案"段** → 答案区里的 `## 四、解答题` 被当成新一段的开头，而这段文本里已经没有"参考答案"那行标题了 ✗ |
| 3 | **题型几乎全错** | 界面上：单选 39 / **多选 0** / **填空 2** / 解答 128；解析层真卷：qtype **全是空** | 题型只从 `【题型】` 标签取，**没有用"卷面小节标题"**（`一、选择题` / `二、多选题` / `三、填空题` / `四、解答题`）—— 而这是试卷里最可靠的信号 |
| 4 | 选项切不全 | 真卷 Q2 得 0 个选项、Q6 得 3 个 | 一行四连 / 与题干同行 / 跨行 三种排法混着来，切分还不够全 |

### P0 实施后的实测（`.probe/v1410p0.cjs`，**12/12 通过**）

| 项 | 修之前 | 修之后 |
|---|---|---|
| 题数 | 24（答案被当成题）| **19** ✓ |
| 题型 | 全空 → 界面 多选 0 / 填空 2 / 解答 128 | **8 单选 / 3 多选 / 3 填空 / 5 解答** ✓ |
| 板块 | 关键词命中即返回、6 个板块、**38% 没板块且看不到** | **打分制 + 10 板块 + "未分类"兜底**；真卷未分类 **2/19（11%）**，且未分类的题在「未分类」下**一定筛得到** ✓ |
| 老题可见性 | 老板块名/空板块在新分类下**筛不到** | `normSection()` 归一化：`概率与统计→计数原理与概率统计`、空/不认识→`未分类`，**老题照常能筛到** ✓ |
| 选项切不全 | 静默（Q2 0 个、Q6 3 个）| **标警告**（"选择题但只切出 N 个选项，请核对"），导入后可优先核对 ✓ |

实现要点：
1. **`parseQuestions` 先整篇剥非题目行（含"参考答案"整段截断）→ 再分块**（顺序反了答案就会被当成题）。
2. 题型两级来源：**小节标题**（`typeOfSegmentHead`：单选题/多选题/填空题/解答题，含"只有一项"这类措辞）+ **结构兜底**（有选项→选择；`\_\_\_` →填空；否则解答）。
3. **区段题号计数回填**：在**原始文本**上数每小节里有几个题号，按顺序把题型发给对应的题 —— 不依赖"标题有没有被当成分块边界"，所以标题怎么被剥都不影响结果。
4. 归类改 **`SECTION_HINTS` 权重打分**（专有名词 5 / 结构词 3 / 泛词 1；最高分 <4 或并列 → 未分类），并补了 **LaTeX 关键词**（`\sin`/`\cos`/`\vec`/`\log`…）—— 实测"已知函数 f(x)=sin2x…"不再被判成"函数与导数"。
5. 新板块表（11 项，末项"未分类"）：集合与逻辑 · 不等式 · 函数与导数 · 三角函数与解三角形 · 平面向量与复数 · 数列 · 立体几何 · 解析几何 · 计数原理与概率统计 · 成对数据与统计案例 · 未分类。

**仍待做**：`#4` 选项切分本身还能再加固（目前靠"标警告"兜住）；**P1 校核面板**（把带警告的题排最前、逐题卡片改）；P2/P3 见附表。

## 二、设计目标（老师视角）

1. **导入一份 PDF → 一眼看出"哪几道不对" → 改完入库**，而不是导完再逐条翻。
2. **按分类一定能看到题**：任何一道题都**必然落在某个可见分类**里（含"未分类"）。
3. **分类能自己长**：允许老师改板块/章节/知识点，改完能复用（记忆 + 批量改）。
4. 组卷要能按**双向细目表**（题型 × 板块 × 难度 × 题量）挑，且分数/知识点分布看得见。

## 三、数据模型（重设计）

```ts
interface Question {
  id: number
  stem: string                 // 题干，正文里用 [图N] 占位
  options: string[]            // 选择题选项（多选也在这）
  answer: string
  solution: string
  images: { n: number; src: string; caption?: string }[]   // data URL，自包含
  // ---- 分类：三级 + 来源 ----
  qtype: QType                 // choice | multi | blank | answer（**必填**，导入时自动定）
  module?: string              // 新课标模块：必修一/必修二/选必一/选必二/选必三
  section: string              // 板块（见下方体系，未定 = '未分类'）
  chapter?: string             // 章节
  points: string[]             // 知识点（可多个，带置信度更好）
  difficulty: 1 | 2 | 3 | 4 | 5
  source: { year?: string; paperName?: string; region?: string; no?: number }
  // ---- 质量与校核 ----
  review?: { state: 'ok' | 'todo' | 'suspect'; notes?: string }
  quality?: { options?: boolean; answer?: boolean; images?: boolean; split?: boolean }
}
```

要点：
- **`section` 永不为空**：猜不出就写 `'未分类'`（于是"未分类"按钮一定能筛到它 ✓）。
- **`quality` 是导入时算出来的"体检结果"**，导入后列表直接按它排序（可疑的排最前）。
- 图用 data URL 自包含（已实现），但**大卷要防 localStorage 5MB 上限**：图另存内容库文件 + 题里存 `assetId`（P2）。

## 四、分类体系（按人教A版 / 新课标）

- **第一级 module**：必修一 · 必修二 · 选择性必修一 · 选择性必修二 · 选择性必修三
- **第二级 section（10 个，覆盖高考全部内容）**：
  1 集合与逻辑 · 2 不等式 · 3 函数与导数 · 4 三角函数与解三角形 · 5 平面向量与复数 ·
  6 数列 · 7 立体几何 · 8 解析几何 · 9 计数原理与概率统计 · 10 成对数据与统计案例 · **未分类**
- **第三级 chapter**：沿用现有 `CHAPTERS`（补齐数列/向量/复数等），并支持自定义。
- **归类算法（替换现在的"关键词命中即返回"）**：
  ```
  score(section) = Σ 命中词权重 × 命中次数
  词权重：专有名词(椭圆/双曲线/等差数列/二项式/独立性检验)=5
          结构词(数列/向量/概率/立体)=3
          泛词(函数/图像/最值/方程)=1     ← 泛词只做加分，不足以单独定类
  取最高分；最高分 < 阈值 或 与第二名同分 → '未分类'（宁可不判，也别判错）
  ```
  （这样才能修掉"三角函数题被判成函数与导数"。）

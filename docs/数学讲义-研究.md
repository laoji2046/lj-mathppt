# 数学讲义编辑器 · 调研报告

> 调研日期 2026-09-21 · 目的：在「PDF 能生成试卷」的基础上，加一个**数学讲义编辑器**。
> 本报告 = ① 讲义在国内高中数学里到底是什么 ② 网上现成工具分了哪几条路线、各能抄什么 ③ 落到我们项目上的设计与分期。
> 结论仅供拍板用 ✓ 代码一行没写 ✓。

## 0. 结论速览

1. **讲义 = 一份可打印、能发给学生的 A4 文档**：知识梳理 + 例题精讲 + 变式 + 当堂练习 + 归纳小结 + 课后作业；同一份内容要能出 **学生版 / 教师版** 两个版本 ✓（国内商品化讲义几乎都是「教师版 + 学生版」成对卖 ✓）。
2. **不做第二个 Word** ✗。我们要做的是「题库 + 试卷」这条基建的**第三条腿**：题目从题库来 ✓、版式沿用现有 A4 打印链 ✓，新增的只有**讲义结构** + **两种版本渲染** + **讲义专属块**（知识框 / 例题框 / 提示 / 留白）✓。
3. 分期：**M1** 讲义文档模型 + 块编辑 + A4 打印 + 学生/教师版一键切换（最小可用 ✓）；**M2** 题库打通（插题 / 抽题 / 知识底座 ✓）；**M3** 交互版与「讲义 ↔ 幻灯片」同源 ✓。
4. ⚠ **命名要先理清**：我们现在把**幻灯片模板**叫「数学讲义模板」✗（模板库那两个标签页 + `pptTheme` 里的 `EduMath · 讲义` ✓）—— 新的讲义编辑器一做，这个词就会打架 ✓ 建议先把那两处改名 ✓。

## 1. 先把词统一：讲义 / 学案 / 教案 / 试卷

| 名字 | 谁用 | 内容重心 | 形态 |
|---|---|---|---|
| **讲义** | 老师讲、学生看与记 | 知识梳理 + 例题精讲 + 变式 + 练习（含答案） | A4 文档 ✓ 常有教师版/学生版 ✓ |
| **学案 / 导学案** | 学生自己走流程 | 学习目标 → 自主学习 → 合作探究 → 当堂检测 → 小结（留白多 ✓） | A4 文档 ✓ 环节名固定 ✓ |
| **教案** | 老师自己 | 教学流程、时间分配、提问设计 | 不外发 ✓ |
| **试卷** | 考 | 只有题（答案另附 ✓） | A4／A3 ✓ 我们**已经能做** ✓ |
| 幻灯片 | 现场演示 | 一页一个点 | 我们**已经能做** ✓ |

→ 我们要做的是**讲义** ✓，但数据模型要能顺手吃下**学案的环节骨架** ✓（同一套块，换一个默认骨架就成 ✓）。

## 2. 国内讲义/学案的实际结构（归纳出来的骨架）

1. **抬头/封面**：学校 · 科目 · 专题名 · 年级 · 教师 · 日期 ✓（我们试卷已有 ✓）
2. **学习目标 / 考情分析** ✓
3. **知识梳理**：定义、公式、定理、易错点 ✓ —— 常见**填空版**（关键处留空，学生边听边填 ✓）这是讲义区别于试卷的关键玩法 ✓
4. **典型例题**：例题 + 解析 + **方法小结** ✓ 常紧跟**变式** ✓
5. **当堂练习 / 随堂检测** ✓
6. **归纳小结**：方法、模型 ✓
7. **课后作业** ✓
8. **答案与提示**：教师版内联 ✓／学生版留空或统一倒排在末尾 ✓

来源：学校《学案编制要求》（「诱思八环」环节定义 ✓ https://www.sdtszx.com/phone/index_message_show.action?message.id=1127 ）、国内讲义商品页（教师版+学生版成对 ✓ https://www.51jiaoxi.com/doc-18814142.html ）、中文试卷/讲义 LaTeX 标准 `exam-zh`（http://mirror.koddos.net/CTAN/macros/xetex/latex/exam-zh/doc/basic/exam-zh-doc-basic.pdf ）。

## 3. 网上工具的四条路线（各能抄什么）

### 3.1 LaTeX 体系（九十年代至今的主力 ✓）
- 代表：`exam-zh`（中文试卷/讲义 ✓）· `ctexart` + `tcolorbox`（块框 ✓）· **`beamerarticle`**（幻灯片与讲义**同源** ✓★）· `tufte-handout`（**边注** ✓）
- **值得抄**：
  - **一份内容两种产物** ✓ —— beamerarticle 正是「同一份源，一边出幻灯片、一边出讲义」✓ 我们有幻灯片 ✓ 这条几乎可以直接借 ✓★
  - **块样式**：tcolorbox 那一套「定义 / 定理 / 例题 / 提示 / 警示」框 ✓（Typst 模板是同一套 ✓ 见下）
  - **边注**：把「易错点 / 旁批」放在页边 ✓ 不打断正文 ✓ 很贴讲义 ✓
- 不适合我们：让老师写 LaTeX ✗

### 3.2 现代排版工具（Quarto / Typst ✓）
- **Quarto**：Markdown 源 → callout（提示/注意/警告 ✓）、定理环境、交叉引用 → 一次出 PDF/HTML ✓（https://quarto.org/docs/authoring/callouts.html ）
- **Typst 讲义模板**：自动**封面 + 目录 + 页眉页脚** ✓；预定义**块类**（Definition / Lemma / Theorem / Corollary ✓ 可加自定义类 ✓）；`notefig()` 管图 ✓
  - https://github.com/BeitianMa/typst-lecture-notes ✓ · https://github.com/jskherman/jsk-lecnotes ✓（后者还配了编辑器代码片段 ✓ 让老师少打字 ✓）
- **值得抄**：**块类型 + 自动编号 + 配色**这一整套 ✓、封面/目录自动化 ✓
- 不适合我们：要装工具链、老师上手难 ✗（但它们能当**导出样式**的参考 ✓）

### 3.3 交互式教材
- 代表：**Mathigon**（Polypad ✓ 白皮书《The Textbook of the Future》✓ https://fr.mathigon.org/downloads/whitepaper.pdf ）、**Ximera**（可交互微积分教材 ✓ https://ximera.osu.edu/csccmathematics/precalculus1/ximeraTutorial/howToUseXimera ）、PreTeXt ✓
- **值得抄**：讲义的**交互版** —— 可拖的图、可展开的答案、随堂自测 ✓ 我们**已经有** GeoGebra / Desmos / 3D / 数理图形 ✓ 做这个比他们省力 ✓
- 不适合现在做：会拖慢「先能用」✗（放 M3 ✓）

### 3.4 国内 AI 出讲义实战
- 一位高中数学老师的完整流程（腾讯云开发者社区 ✓ 2026-05 ✓ https://cloud.tencent.cn/developer/article/2663569 ）：
  1. **学生档案**（薄弱点写成 Markdown ✓ 下次自动读 ✓）
  2. **知识底座**（本地按模块整理：概念 / 公式 / 解题模型 / 易错点 ✓ 生成时直接调 ✓）
  3. 生成讲义 → **学生版（无答案）/ 教师版（含答案 + 批注）** ✓
  4. 出稿时间从 2–3 小时压到约 15 分钟 ✓
- **值得抄**：**学生档案 + 知识底座**这两个库的思路 ✓ 与我们的题库天然是一家人 ✓（知识底座 ≈ 我们的知识点/方法库 ✓）
- 不照搬：**不替老师写内容** ✗（与我们既有纪律一致 ✓ 我们自动化的是「结构 / 排版 / 抽题」✓ 内容由老师定 ✓）

## 4. 落到 LJ-MathSlides 上

### 4.1 已经有的（不用重造 ✓）
| 现有件 | 对讲义意味着什么 |
|---|---|
| `PaperModal.vue`（101KB / 1659 行 ✓） | A4 纸张 + 打印链 + 页眉页脚 + 图/公式/表格排版 ✓ —— 讲义**共用这套渲染与打印** ✓ |
| `ui/paper.ts`（题库→试卷接收口 ✓） | 讲义再加一个同样形态的接收口即可 ✓ |
| `pdfImport.ts` | **已经在处理讲义版 PDF 的页眉页脚** ✓（源码注释里就写着讲义书名、页码 ✓）—— 导入侧早有讲义经验 ✓ |
| 题库（题目/选项/答案/解析/图/知识点 ✓ + §19 组卷方案 ✓） | 讲义的例题、练习、作业都从这里来 ✓ |
| 图形与公式（`mathPlot` / 3D / GeoGebra / Desmos / MathJax ✓） | 知识点配图、动态图直接可用 ✓ |

### 4.2 需要新增：数据模型草案

```
Handout = {
  meta:  { 学校, 科目, 专题, 年级, 教师, 日期, 版本: 'student' | 'teacher' },
  outline: [ 章 → 节 … ],                 // 左侧大纲树的来源
  blocks:  [ Block … ]                    // 顺序块；章节点也是块（type: 'heading'）
}

Block = {
  id, type, content,
  // 讲义专属块：目标 / 知识梳理 / 例题 / 变式 / 练习 / 小结 / 提示 / 警示 / 填空留白
  // 通用块：标题 / 正文 / 公式 / 图 / 表 / 分页
  ref?:  { qid } ,                        // 例题/练习可直接**引用题库题**（不是复制 ✓ 改题同步 ✓）
  render: {                               // ★ 讲义与试卷最大的不同就在这里
    student: 'inline' | 'hide' | 'blank' | 'endnote',   // 答案/解析：学生版隐藏、留白或倒排到末尾 ✓
    teacher: 'inline' | 'hide' | 'endnote',             // 教师版一般 inline + 批注 ✓
  },
  number?: boolean, style?: { color, box } 
}
```

### 4.3 编辑器形态（建议）
- **不做自由画布** ✗（那是幻灯片 ✓ 也是 Word 的活 ✓）→ 讲义用**单栏文档流 + 块插入** ✓
- 版式：左**大纲树**（章/节/块）· 中**A4 纸预览**（直接复用试卷的纸张与字体体系 ✓）· 右**块属性**（版本渲染 / 编号 / 配色 ✓）
- 顶部一条**版本切换（学生版 ⇄ 教师版）** ✓★ + 导出 PDF ✓ + 插入题库题 ✓
- 交互细节照已有习惯：块可拖、可折叠、Tab 缩进、Ctrl+Z 全程可撤销 ✓

### 4.4 与试卷 / 幻灯片的关系（本次最大的架构收益 ✓）
- 同一道题三种排版：**试卷**（考 ✓ 无解析）/ **讲义**（讲 ✓ 带解析与方法小结）/ **幻灯片**（演 ✓ 一页一点）
  → 三边共享「题库 → 排版模板」这一条管线 ✓ 而不是各写一套 ✗
- 「讲义 ↔ 幻灯片」同源（beamerarticle 思路 ✓）放 M3：讲义的一个例题块 → 一键生成一页幻灯片 ✓

## 5. 分期与验收

**M1 · 最小可用**（建议先做这个 ✓）
- 讲义文档模型 + 块编辑（标题/正文/公式/图/表/知识框/例题/练习/答案/留白 ✓）
- A4 打印与导出 PDF ✓（复用试卷链 ✓）
- **学生版 / 教师版一键切换** ✓（验收核心 ✓）
- 存/开（跟文稿同一套保存体系 ✓）
- 验收：做一份两页讲义 → 两个版本各打印一次 → 学生版**没有**答案、教师版有答案与批注 ✓（探针 + 真机截图 ✓）

**M2 · 题库打通**
- 插单题 ✓ 按知识点/难度**抽题组讲义** ✓（例题池与练习池分开 ✓ 复用 §19 组卷方案的抽题算法 ✓）
- **知识底座**：按模块存公式 / 模型 / 易错点 ✓ 一键插入知识梳理块 ✓（对应 §3.4 那位老师的做法 ✓）

**M3 · 交互与同源**
- 讲义里嵌 GeoGebra / 3D / 数理图形 ✓ 答案可展开 ✓ 导出 HTML（给学生平板 ✓）
- 讲义 ↔ 幻灯片互转 ✓

## 6. 风险与「不做」清单
- ✗ 不做自由画布排版（幻灯片已经覆盖 ✓）
- ✗ 不做 LaTeX/Typst 全文导出（除非以后要投稿 ✓；但「块 → LaTeX 片段」是廉价加分项 ✓ 可留 M3 ✓）
- ✗ 不做 AI 自动写讲义内容（老师对内容负责 ✓ 与我们一贯纪律一致 ✓）—— 但**结构、排版、抽题**可以自动化 ✓
- ⚠ 命名冲突先解决（见 §0 第 4 条 ✓）
- ⚠ 讲义与试卷**共用打印链**时要小心：试卷是密排 + 分栏，讲义是疏排 + 留白 ✓ 纸张样式要**参数化**而不是复制一份 ✗

## 三、说明

- **「缺答案」里最该先补的是选择/多选**（`choice`/`multi`）——这几道若答案空，整题基本不能用；
  填空（`blank`）次之；解答题（`answer`）本来就不给独立答案，缺的是 `## 解析`。
- **源里根本没有答案的卷**（`2026 年全国 I 卷`/`II 卷`/`北京卷`，来自 `2026年.pdf`）：
  这不是解析失败，是那份 MinerU 产物只有题干（`【答案】`/`故选` 命中 0 次）→ 得另找带答案的源。
- **更省力的补法**：这些卷目录里都有 MinerU 的 `*_content_list.json`，那是 App 的原生入口
  （见 `docs/题库-参考实现对照.md`），保真度高于从 `full.md` 反推；缺的答案优先走那条路回灌。
- 补完后重新导入 App（录入试题 → 按 Markdown 解析 → 校对表核对 → 入库）即可。

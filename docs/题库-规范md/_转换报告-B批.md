## 已知局限（MinerU 原始 md 的固有噪声）

- 卷面 OCR 残留：少数变量被识别成 `�`，**必须人工核对**；
- 「选项本身是图」的题（如蚌埠 Q6）不硬切选项，整块留在 `## 题目` 里以保图不丢；
- 选择题答案优先取卷尾 HTML 表格，其次取流水串 / 解析里的「故选X」；三处都没有的会「缺答案」；
- 解答题的 `## 解析` 按「N. (x分) 解：」切片，跨页断裂处可能不全；
- `section` / `level` / `difficulty` 一律不写（规范 §6 不猜），导入时由 App 自动归类。

## 挖缺（第二轮修复，硬缺口 47 → 45）

| 症状 | 原因 | 修法 |
|---|---|---|
| 下一题题号粘在上一题解析末尾（`…故选：B.7.一百零八塔…`）→ Q7 整题丢失 | 题号不在行首 | `unglue()`：句末标点 + `N.` + 非数字处补换行 |
| 题干被 OCR 塞进 `<table><tr><td>`（`2026 年全国 I 卷-2` 的 Q14）→ 整题丢失 | 表格标签不是换行 | `expand_tags()`：表格标签当换行（`parse_tables` 仍用原始 HTML） |
| `14.5,7 【解析】…` 这类答案漏取 | 「含多个 `N.` 就跳过」误杀长解析行 | 改为只在 `is_answer_run()`（真流水串）时跳过 |
| `…最大值为 $\sqrt[3]{3/2}$ 【答案】`（标记在行尾、值为空）| OCR 把值和标记顺序搞反 | `build()` 回退取 head 末尾的 `$…$`，并从题干摘掉 |
| 答案/解析尾部残留裸 `##`、`---`、`<td>` | 源里的分页/表格噪声 | `tidy()` 统一清除 |
| `expand_tags` 拆出的 `87.`/`0.` 假题号 | 碎片行被当成新题 | 卡题号范围 `1..30` 且题干非空 |

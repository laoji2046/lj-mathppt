# 平面图形：可拖控制点（平行四边形 / 圆弧 / 圆）

> v2026.09.1395。代码：`src/composables/planeCtrl.ts`（几何）+ `MathFigureElement.vue`（画图与拖拽）+ `PropertyPanel.vue`（数字面板）。

## 一、平行四边形（可拖边长 / 夹角）

图形库 → 平面图形 → **平行四边形（可拖边长/夹角）**。

- **A 点固定**（版面左上内侧），**两个蓝色控制点 B、D 就是两条邻边**：
  - 拖 **B** → 改边 AB 的**长度与方向**；
  - 拖 **D** → 改边 AD 的**长度与方向** ⇒ 夹角 ∠DAB 随之变化。
  - 第四个顶点 C 由 C = B + D − A 自动算出，永远是平行四边形。
- 属性面板里「平行四边形」框直接给**三个数**，可以**直接输入**：
  | 数字 | 含义 |
  |---|---|
  | 边长 AB | AB 的长度（像素）。改了以后**方向不变**，只改长度 |
  | 边长 AD | AD 的长度（像素） |
  | 夹角 ∠DAB | 0–180°，改它时 **AD 长度不变**，只把 AD 绕 A 转过去 |
- **老图元不变**：默认控制点画出来与以前"平行四边形"卡片的四个顶点**数值完全一致**（88,0 / 400,0 / 312,300 / 0,300）。

## 二、圆弧

### 2.1 圆弧（圆心 + 圆心角）
图形库 → 平面图形 → **圆弧（圆心 + 圆心角）**。三个蓝色控制点：

| 控制点 | 拖动效果 |
|---|---|
| 圆心 | 整条弧平移（半径、圆心角都不变） |
| 起点 | 改**半径**与**起始角**（= 到圆心的距离与方向） |
| 终点 | 改**圆心角**（半径不变） |

面板里三个数都能直接输入：**半径 r（px）／起始角（°）／圆心角（°）**。
圆心角**带符号、可超过 180°**（正 = 屏幕上的顺时针）：输入 270 就是四分之三圆，
输入 −300 就是逆时针的长弧。（端点本身区分不出"长弧/短弧"，所以这个数单独存在元素上。）

### 2.2 圆弧（过三点）
图形库 → 平面图形 → **圆弧（过三点）**。三个控制点就是要经过的三点：
程序求出它们的**外心与半径**，从第一点画到第三点、**中间那个点一定落在弧上**。
面板显示半径 R（算出来的，不能直接改）。
三点共线时定不出圆 → 图上先画一条虚线兜底，并给一行提示；把控制点拖开即可。

### 2.3 椭圆弧（a、b、起始角 + 圆心角）
图形库 → 平面图形 → **椭圆弧（a、b、起始角 + 圆心角）**。**5 个蓝色控制点**：

| 控制点 | 拖动效果 |
|---|---|
| 中心 | 整体平移 |
| a 端点（右侧那个） | 改**半长轴 a**（只取水平距离） |
| b 端点（下方那个） | 改**半短轴 b**（只取垂直距离） |
| 起点 | 改**起始角 θ₀**（轴长不变） |
| 终点 | 改**圆心角 Δθ**（轴长不变） |

面板里四个数**都能直接输入**：`半长轴 a（px）／半短轴 b（px）／起始角 θ₀（°）／圆心角 Δθ（°）`。

> ⚠ 这里的 θ 是**参数角**：P(θ) = 中心 + (a·cosθ, b·sinθ)，**不是极角、也不是弧长**。
> 椭圆上同一个点只对应一个参数角，用它控弧的范围最方便（教科书也这么标）。
>
> - **Δθ = 360° 就是整条椭圆**（界面上会画成 `<ellipse>`，不是一段弧）。
> - Δθ 可以**带符号、可超过 180°**（正 = 屏幕上的顺时针）。
> - a、b 是**像素**：把元素框拉扁，椭圆也跟着扁 —— 这是椭圆的定义，不是"被压扁的圆"。

### 2.4 椭圆（a、b 可拖）
图形库 → 平面图形 → **椭圆（a、b 可拖）**。整条椭圆，**3 个控制点**：中心 / a 端点 / b 端点
（拖 a 端点只改 a、拖 b 端点只改 b，与椭圆弧同一套手感）。面板里 `半长轴 a（px）／半短轴 b（px）` 可直接输入。

> 想要弧、不要整条？用上面的**椭圆弧**；反过来，椭圆弧把 Δθ 设成 360° 也会画成整条椭圆。

## 三、圆（圆心 + 指定半径）

图形库 → 平面图形 → **圆（圆心 + 指定半径）**。两个控制点：**圆心** 与 **圆上一点**。

- 拖圆上那点 = 改半径；拖圆心 = 平移。
- 面板里**直接输入半径 r（px）**——这就是"以某点为圆心、以指定值为半径"。

## 四、几个实现上的讲究（给以后的自己）

- 控制点存元素的 `ctrl`，坐标是**归一化 0..1**（随元素框缩放）；但**长度/半径一律在像素里算**，
  所以元素框不管是 600×200 还是 200×600，圆与弧都还是**正圆**（不会被压成椭圆）。
- 圆弧的端点**定不出长弧还是短弧**（270° 与 −90° 端点一样）→ 圆心角单独存 `arcSweep`。
- 角度用**屏幕坐标**（x 右、y 下）：0° 朝右、正角 = 屏幕上顺时针，与 SVG 的 `A` 命令 sweep-flag=1 同向，
  画弧不用翻符号。`|圆心角| > 180` 时 large-arc-flag = 1。
- 控制点是**蓝色**的（圆锥曲线的标注点是橙色），一眼能分开；拖拽**不夹在元素框内**（想拖出去也行）。

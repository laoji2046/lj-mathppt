# RevealSlidr 🎬

**Reveal.js 所见即所得幻灯片编辑器** —— 一款离线、桌面版的演示文稿制作工具。

基于 **Tauri 2 (Rust)** + **Reveal.js** 构建，内置 GeoGebra 与 Desmos 数学工具，适合教师备课、数学/理科课件，以及任何需要精美演示稿的场景。

> 当前版本：**v1.0.0**　|　支持平台：**Windows 10 / 11 (x64)**

---

## ✨ 功能特性

### 🖥️ 所见即所得编辑
- 直接在幻灯片画布上编辑文字、图形、表格、图表、图片，所见即所得
- 多页面管理：新增、删除、拖拽排序、复制、页面缩略图预览
- 矢量绘制与排列工具：图层管理、对齐/分布、组合/解除组合

### 🎨 模板库（内置 90+ 布局）
| 分类 | 说明 |
|---|---|
| **基础布局**（22 种） | 封面、内容、双栏、图片、代码、引用、分区、Bento、统计、卡片、清单、路线图、问答等 |
| **教学模板**（20 种） | 知识总结、例题、多解、易错点、方法总结、试卷题、公式卡、对比、思维导图、练习题、板书等 |
| **专业模板**（36 种） | 商务封面、目录、节标题、团队、服务、数据、对比、时间线、步骤、引用、致谢等（含 4 款极简风） |

- **三套配色主题**：商务蓝 / 深色科技 / 自然清新，一键切换
- **SmartArt 图示库**：流程、层次、矩阵、棱锥、循环、维恩、列表、放射 8 类图示
- **替换背景不丢元素**：可为当前页套用模板背景，保留已有内容

### 🔢 数学与科学工具
- **GeoGebra** 数学引擎（本地离线渲染，3D 支持）——可插入可交互的数学小程序
- **Desmos** 计算器（支持自己的 API Key）
- **公式支持**：数学公式渲染（MathJax）
- **Asymptote** 绘图脚本插入

### 📦 导入 / 导出
- **项目文件**：`.revealslidr.json`（保存 / 打开，自动备份）
- **导出 HTML**：独立网页演示，离线可用
- **导出 PDF**：通过浏览器打印另存
- **导出 PNG**：当前页图片
- **版本历史**：内置版本控制，可随时回退

### 🎤 演示模式
- 全屏播放、自动播放、循环播放、黑白屏
- **演讲者备注**：计时器 + 上一张/下一张缩略图 + 备注
- 快捷键帮助（中文）、搜索、缩放、概览（宫格）
- 底部控制条：悬停呼出

### 🌐 其它
- **完全离线**：Reveal.js、GeoGebra 引擎随应用打包，无需联网
- **品牌定制**：专属 Logo、版权页脚
- 自动保存 + 可恢复

## 📥 安装

### 方式一：安装版（推荐）
运行 `LJ-PPT_1.0.0_x64-setup.exe`（约 25.5MB），按提示完成安装，桌面/开始菜单生成快捷方式。

### 方式二：便携版
单个 `revealslidr.exe`（约 35.6MB）**即拷即用**，无需安装、无需附带任何文件夹。

> ✅ Reveal.js 与 GeoGebra 离线引擎已内嵌进 exe，可完全离线使用（2026-08-29 实测：无 `dist\` 文件夹也能正常启动）。
> ℹ️ 目标电脑需具备 **WebView2 运行时**（Windows 10/11 通常已自带）。
> ℹ️ Desmos 计算器、MathJax 公式、Google Fonts 仍需联网（首次用到时才加载）。

## 🚀 快速上手

1. 启动应用，进入空白演示
2. 点击顶部 **「+」添加幻灯片**，或 **「模板」** 打开模板库挑选一个布局
3. 在画布上直接编辑内容；左侧是页面缩略图，右侧是属性面板
4. 点击 **「演示」** 进入全屏播放；按 **「S」** 打开演讲者备注
5. 制作完成点 **「导出」**，选择 HTML / PDF / PNG

## 🛠️ 开发与构建（可选）

需要 [Node.js](https://nodejs.org)、[Rust](https://www.rust-lang.org/) 和 [Tauri CLI](https://v2.tauri.app/)。

```bash
# 安装依赖
npm install

# 修改 app.js / styles.css / index.html 后同步到两个 dist 目录
#   dist\                              （开发用）
#   src-tauri\target\release\dist\     （打包用）
# 记得在 index.html 里更新版本号 app.js?v=N / styles.css?v=N

# 构建安装版（NSIS）
npm run build
# 产物：src-tauri\target\release\bundle\nsis\RevealSlidr_1.0.0_x64-setup.exe
```

> 🔒 应用自身的三个源码文件（`index.html` / `app.js` / `styles.css`）已**内嵌进 exe 从内存提供**，安装目录中不暴露源码；`dist\` 下仅保留开源的 Reveal.js 与 GeoGebra 运行库。

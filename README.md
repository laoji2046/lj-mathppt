# LJ-PPT 📽️

**Reveal.js 所见即所得幻灯片编辑器** —— 一款**完全离线**、桌面版的演示文稿制作工具。

基于 **Tauri 2 (Rust)** + **Reveal.js** 构建，内置 GeoGebra、Desmos 与 MathJax 数学引擎，特别适合教师备课、数学 / 理科课件，以及任何需要精美演示稿的场景。

> 当前版本：**v1.0.0**　|　支持平台：**Windows 10 / 11 (x64)**

---

## ✨ 功能特性

### 🖥️ 所见即所得编辑
- 直接在幻灯片画布上编辑文字、图形、表格、图表、图片，所见即所得
- 多页面管理：新增、删除、拖拽排序、复制、缩略图预览
- 矢量绘制与排列：图层管理、对齐 / 分布、组合 / 取消组合

### 🎨 模板库（内置 90+ 布局）
| 分类 | 说明 |
|---|---|
| **基础布局**（22 种） | 封面、内容、双栏、图片、代码、引用、分区、Bento、统计、卡片、清单、路线图、问答等 |
| **教学模板**（21 种） | 知识总结、例题、多解、易错点、方法总结、试卷题、公式卡、对比、思维导图、练习题、板书等 |
| **高中数学讲义** | 封面、公式定理、典型例题、证明题、一题多解、知识框架、课堂笔记、练习、易错警示、函数图像、综合大题、考点归纳、章节小结等 |
| **专业模板**（36 种） | 商务封面、目录、节标题、团队、服务、数据、对比、时间线、步骤、引用、致谢等（含极简风） |

- 三套配色主题：商务蓝 / 深色科技 / 自然清新，一键切换
- **SmartArt 图示库**：流程、层次、矩阵、棱锥、循环、维恩、列表、放射 8 类图示
- **数学图形**：平面几何（三角形、梯形、圆+内接三角形…）、立体几何（正方体、长方体、棱锥、圆柱…）、函数曲线（抛物线、正弦、余弦、指数、对数…）、集合 Venn（交/并/补/差/子集，阴影+集合名）
- 替换背景不丢元素：套用模板背景时保留已有内容

### 🔢 数学与科学工具
- **GeoGebra** 数学引擎（本地离线渲染，3D 支持）—— 可插入可交互的数学小程序
- **Desmos** 计算器（本地引擎，支持自己的 API Key）
- **MathJax** 公式渲染（本地引擎）
- **组合公式**：粘贴标准 LaTeX，自动识别中文+公式混排、实时预览、预设模板（不等式链 / 对数平均 / 指数平均等）

### 📦 导入 / 导出
- 项目文件：`.revealslidr.json`（保存 / 打开，自动备份）
- 导出 HTML：独立网页演示，离线可用
- 导出 PDF：浏览器打印另存
- 导出 PNG：当前页图片
- 版本历史：内置版本控制，可随时回退

### 🎤 演示模式
- 全屏播放、自动播放、循环播放、黑白屏
- 演讲者备注：计时器 + 上 / 下一页缩略图 + 备注
- 快捷键帮助（中文）、搜索、缩放、概览（宫格）
- 底部控制条：悬停呼出

### 🌐 其它
- **完全离线**：Reveal.js、GeoGebra、Desmos、MathJax 引擎全部随应用打包，**无网络也正常**（2026-08-29 实测）
- 品牌定制：专属 Logo、版权页脚
- 自动保存 + 可恢复

## 📥 安装

运行 `LJ-PPT_1.0.0_x64-setup.exe`（约 27MB），按提示安装，桌面 / 开始菜单生成快捷方式。

> ✅ 全部离线引擎已内嵌，可完全离线使用。
> ℹ️ 目标电脑需具备 **WebView2 运行时**（Windows 10/11 通常已自带）。

---

## 🚀 快速上手

1. 启动应用，进入空白演示
2. 顶部 **「+」添加幻灯片**，或 **「模板」** 打开模板库挑一个布局
3. 在画布上直接编辑；左侧是页面缩略图，右侧是属性面板
4. **「演示」** 进入全屏播放；按 **「S」** 打开演讲者备注
5. 完成点 **「导出」**，选 HTML / PDF / PNG

## 🛠️ 开发与构建（可选）

需要 [Node.js](https://nodejs.org)、[Rust](https://www.rust-lang.org/) 和 [Tauri CLI](https://v2.tauri.app/)。

```bash
# 安装依赖
npm install

# 构建安装版（NSIS）
npm run build
# 产物：src-tauri\target\release\bundle\nsis\LJ-PPT_1.0.0_x64-setup.exe
```

> 引擎资源（Reveal.js / GeoGebra / Desmos / MathJax）随 `dist/` 打进产物；引擎与安装包体积较大，故安装包与引擎走 **GitHub Releases** 分发。

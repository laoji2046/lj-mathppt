# §1.3 集合的基本运算

> **教材位置**：第一章 · §1.3 集合的基本运算  
> **建议时长**：约 120 min（2 h）  
> **前置知识**：§1.1 集合的概念，§1.2 子集与 Venn 图

---

## 本节目标

1. 理解并集、交集、补集的含义，正确使用符号 $\cup$、$\cap$、$\complement$；
2. 能在给定全集下求补集，会用 Venn 图表示运算结果；
3. 掌握德摩根律，能进行简单的集合运算与化简。

## 二、新知讲解（45 min）

> 📖 以下定义、表述均摘自教材 **§1.3**，与课本逐字一致（符号已转为 LaTeX）。

### 2.1 并集（教材 P10）

**定义：** 一般地，由所有属于集合 $A$ 或属于集合 $B$ 的元素组成的集合，称为集合 $A$ 与 $B$ 的**并集**（union set），记作 $A \cup B$（读作“$A$ 并 $B$”），即

$$A \cup B = \{x \mid x \in A \text{，或 } x \in B\}$$

可用 Venn 图表示。

### 2.2 交集（教材 P11）

**定义：** 一般地，由所有属于集合 $A$ 且属于集合 $B$ 的元素组成的集合，称为集合 $A$ 与 $B$ 的**交集**（intersection set），记作 $A \cap B$（读作“$A$ 交 $B$”），即

$$A \cap B = \{x \mid x \in A \text{，且 } x \in B\}$$

可用 Venn 图表示。

### 2.3 全集（教材 P12）

**定义：** 一般地，如果一个集合含有所研究问题中涉及的所有元素，那么就称这个集合为**全集**（universal set），通常记作 $U$。

### 2.4 补集（教材 P13）

**定义：** 对于一个集合 $A$，由全集 $U$ 中不属于集合 $A$ 的所有元素组成的集合称为集合 $A$ 相对于全集 $U$ 的**补集**（complementary set），简称为集合 $A$ 的补集，记作 $\complement_U A$，即

$$\complement_U A = \{x \mid x \in U \text{，且 } x \notin A\}$$

可用 Venn 图表示。

## 三、例题（40 min）

### 例 1（基础）

**题目：** 设 $U = \{1, 2, 3, 4, 5\}$，$A = \{1, 2, 3\}$，$B = \{2, 3, 4\}$，求 $A \cup B$、$A \cap B$、$\complement_U A$。

**解：**

$$A \cup B = \{1, 2, 3, 4\}$$

$$A \cap B = \{2, 3\}$$

$$\complement_U A = \{4, 5\}$$

---

### 例 2（综合）

**题目：** 已知 $U = \mathbb{R}$，$A = \{x \mid -1 \le x < 3\}$，$B = \{x \mid x \ge 0\}$，求 $A \cup B$、$A \cap B$、$\complement_U A$（用区间表示）。

**解：**

$$A \cup B = \{x \mid x \ge -1\} = [-1, +\infty)$$

$$A \cap B = \{x \mid 0 \le x < 3\} = [0, 3)$$

$$\complement_U A = \{x \mid x < -1 \text{ 或 } x \ge 3\} = (-\infty, -1) \cup [3, +\infty)$$

---

### 例 3（拓展）

**题目：** 设 $U = \mathbb{R}$，$A = \{x \mid x \ge -1\}$，$B = \{x \mid x \le 2\}$，求 $\complement_U (A \cap B)$，并验证德摩根律 $\complement_U (A \cap B) = (\complement_U A) \cup (\complement_U B)$。

**解：**

$$A \cap B = [-1, 2]$$

$$\complement_U (A \cap B) = (-\infty, -1) \cup (2, +\infty)$$

又 $\complement_U A = (-\infty, -1)$，$\complement_U B = (2, +\infty)$，故

$$(\complement_U A) \cup (\complement_U B) = (-\infty, -1) \cup (2, +\infty)$$

两边相等，德摩根律验证成立。

> **课堂提示**：德摩根律在含「非」「且」「或」的逻辑化简中反复出现，与 §1.4、§1.5 逻辑语言相通。

## 五、易错点与小结（15 min）

### 易错点

| 错因 | 正解 |
|------|------|
| 并集中重复计数 | $A \cup B$ 中每个元素只出现一次 |
| 忽略全集 $U$ | 补集必须明确相对于哪个全集 |
| 区间端点遗漏 | 注意开区间、闭区间与 $\complement$ 的端点 |
| 德摩根律符号写反 | 「并的补 = 补的交」 |

### 小结

- **并** $A \cup B$：至少属于其一
- **交** $A \cap B$：同时属于两者
- **补** $\complement_U A$：在 $U$ 中但不在 $A$ 中
- 德摩根律连接「补」与「并、交」

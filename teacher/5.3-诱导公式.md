# §5.3 诱导公式

> **教材位置**：第五章 · §5.3 诱导公式  
> **建议时长**：约 120 min（2 h）  
> **前置知识**：§5.2 三角函数定义、单位圆、各象限符号

---

## 本节目标

1. 熟记 $\pi \pm \alpha$、$-\alpha$、$\dfrac{\pi}{2} \pm \alpha$ 等诱导公式；
2. 能利用诱导公式将任意角的三角函数化为锐角三角函数；
3. 掌握口诀「奇变偶不变，符号看象限」并能正确运用。

---

## 一、复习引入（15 min）

**复习提问：**

- $\sin 150°$、$\cos(-60°)$、$\tan\dfrac{7\pi}{4}$ 能否用锐角三角函数表示？
- 单位圆上，角 $\alpha$ 与 $\pi - \alpha$ 的终边有何对称关系？

**情境：**

> 计算 $\sin 390°$、$\cos\dfrac{11\pi}{6}$ 时，不必查表——诱导公式把「大角、负角」化为「小锐角」。

## 二、新知讲解（45 min）

> 📖 以下公式均摘自教材 **§5.3**，与课本逐字一致（符号已转为 LaTeX）。

### 2.1 公式二至公式四（教材 P190–P192）

**公式二（教材 P190）：** $\sin(\pi - \alpha) = \sin \alpha$，$\cos(\pi - \alpha) = -\cos \alpha$，$\tan(\pi - \alpha) = -\tan \alpha$。

**公式三（教材 P191）：** $\sin(-\alpha) = -\sin \alpha$，$\cos(-\alpha) = \cos \alpha$，$\tan(-\alpha) = -\tan \alpha$。

**公式四（教材 P192）：** $\sin(\pi + \alpha) = -\sin \alpha$，$\cos(\pi + \alpha) = -\cos \alpha$，$\tan(\pi + \alpha) = \tan \alpha$。

### 2.2 公式五与公式六（教材 P193–P194）

**公式五（教材 P193）：** $\sin\left(\dfrac{\pi}{2} - \alpha\right) = \cos \alpha$，$\cos\left(\dfrac{\pi}{2} - \alpha\right) = \sin \alpha$。

**公式六（教材 P194）：** $\sin\left(\dfrac{\pi}{2} + \alpha\right) = \cos \alpha$，$\cos\left(\dfrac{\pi}{2} + \alpha\right) = -\sin \alpha$。

### 2.3 记忆方法（教材 P194）

**口诀：** 奇变偶不变，符号看象限。

## 三、例题（40 min）

### 例 1（基础）

**题目：** 求值：

（1）$\sin 150°$；  
（2）$\cos(-\dfrac{5\pi}{3})$；  
（3）$\tan\dfrac{11\pi}{6}$。

**解：**

（1）$\sin 150° = \sin(180° - 30°) = \sin 30° = \dfrac{1}{2}$。  
（2）$\cos\left(-\dfrac{5\pi}{3}\right) = \cos\dfrac{5\pi}{3} = \cos\left(2\pi - \dfrac{\pi}{3}\right) = \cos\dfrac{\pi}{3} = \dfrac{1}{2}$。  
（3）$\tan\dfrac{11\pi}{6} = \tan\left(2\pi - \dfrac{\pi}{6}\right) = -\tan\dfrac{\pi}{6} = -\dfrac{\sqrt{3}}{3}$。

---

### 例 2（综合）

**题目：** 化简：$\dfrac{\sin(2\pi - \alpha)\cos(\pi + \alpha)}{\tan(\pi - \alpha)\sin(\pi/2 + \alpha)}$。

**解：**

分子：$\sin(2\pi-\alpha) = -\sin\alpha$，$\cos(\pi+\alpha) = -\cos\alpha$，积为 $\sin\alpha\cos\alpha$。

分母：$\tan(\pi-\alpha) = -\tan\alpha$，$\sin(\pi/2+\alpha) = \cos\alpha$。

原式 $= \dfrac{\sin\alpha\cos\alpha}{-\tan\alpha \cdot \cos\alpha} = -\dfrac{\sin\alpha}{\tan\alpha} = -\cos\alpha$（$\cos\alpha \ne 0$）。

---

### 例 3（拓展）

**题目：** 已知 $\sin\alpha = \dfrac{3}{5}$，$\alpha \in \left(\dfrac{\pi}{2}, \pi\right)$，求 $\sin\left(\dfrac{\pi}{2} + \alpha\right)$、$\cos\left(\dfrac{\pi}{2} - \alpha\right)$。

**解：**

$\alpha$ 在第二象限，$\cos\alpha = -\dfrac{4}{5}$。

$$\sin\left(\frac{\pi}{2} + \alpha\right) = \cos\alpha = -\frac{4}{5}.$$

$$\cos\left(\frac{\pi}{2} - \alpha\right) = \sin\alpha = \frac{3}{5}.$$

## 五、易错点与小结（15 min）

### 易错点

| 错因 | 正解 |
|------|------|
| 「符号看象限」看成变换后的函数 | 看**原函数名**在原角所在象限的符号 |
| $\dfrac{\pi}{2}+\alpha$ 误用 $\sin \to \sin$ | $k=1$ 为奇，应变为 $\cos$ |
| 角度制与弧度制混用诱导 | 公式对两种度量均成立，但勿混写单位 |
| 化简时分母为 0 未讨论 | 注明使分母为零的 $\alpha$ 需排除 |

### 小结

- 核心：$\pi \pm \alpha$、$-\alpha$、$\dfrac{\pi}{2} \pm \alpha$
- 口诀：**奇变偶不变，符号看象限**
- 目标：任意角 $\to$ 锐角 $\to$ 求值

## 二、核心定义汇编（45 min）

> 📖 以下为核心定义汇编，均摘自教材第三章，与课本逐字一致（符号已转为 LaTeX）。

### 2.1 §3.1 函数的概念及其表示

**函数（P62）：** 设 $A$，$B$ 是非空的实数集，若 $\forall x \in A$，按确定对应关系 $f$ 在 $B$ 中有唯一 $y$ 对应，则 $f:A\to B$ 为函数，记 $y=f(x)$，$x\in A$。$x$ 为自变量，$A$ 为定义域，$\{f(x)\mid x\in A\}$ 为值域。

**同一函数（P66）：** 定义域相同且对应关系完全一致。

**分段函数（P74）：** 在定义域不同部分用不同解析式表示的函数。

### 2.2 §3.2 函数的基本性质

**单调性（P77）：** 在区间 $D$ 上，$x_1<x_2 \Rightarrow f(x_1)<f(x_2)$ 为单调递增；$f(x_1)>f(x_2)$ 为单调递减；$D$ 为单调区间。

**最大值（P80）：** 存在 $M$ 使 $\forall x\in I$，$f(x)\le M$，且 $\exists x_0\in I$，$f(x_0)=M$。

**偶函数 / 奇函数（P83–P84）：** 定义域 $I$ 关于原点对称，且 $f(-x)=f(x)$ 或 $f(-x)=-f(x)$。

### 2.3 §3.3 幂函数

**定义（P89）：** $y=x^\alpha$（$x$ 为自变量，$\alpha$ 为常数）为幂函数；本节研究 $\alpha=1,2,3,\tfrac{1}{2},-1$。

### 2.4 §3.4 函数的应用（一）

**建模思想（P93）：** 利用一次函数、二次函数、幂函数等函数模型解决实际问题；在闭区间上单调的函数，最值在端点取得。

## 二、典型例题回顾（40 min）

### 例 1（概念与定义域）

**题目：** 求函数 $f(x) = \dfrac{\sqrt{x^2 - 1}}{x - 2}$ 的定义域。

**解：**

需 $x^2 - 1 \ge 0$ 且 $x - 2 \ne 0$，即 $|x| \ge 1$ 且 $x \ne 2$。

定义域为 $(-\infty, -2) \cup (-2, -1] \cup [1, 2) \cup (2, +\infty)$。

---

### 例 2（单调性与奇偶性）

**题目：** 已知 $f(x)$ 是 $\mathbb{R}$ 上奇函数，在 $(0,+\infty)$ 上单调递减，且 $f(1) = -2$，求满足 $f(x) < 2$ 的 $x$ 的取值范围。

**解：**

$f$ 为奇 $\Rightarrow$ $f(-1) = 2$。

在 $(0,+\infty)$ 减 $\Rightarrow$ 在 $(-\infty,0)$ 减（奇函数性质）。

$f(x) < 2 = f(-1)$：

- $x > 0$：减函数，$f(x) < f(1)$ 即 $x > 1$；
- $x < 0$：减函数，$f(x) < f(-1)$ 即 $x < -1$。

故 $x \in (-\infty, -1) \cup (1, +\infty)$。

---

### 例 3（幂函数与大小比较）

**题目：** 比较 $0.4^{0.2}$、$0.4^{0.4}$、$0.2^{0.4}$ 的大小。

**解：**

$y = 0.4^x$ 在 $\mathbb{R}$ 上减，$0.2 < 0.4$ $\Rightarrow$ $0.4^{0.2} > 0.4^{0.4}$。

$y = x^{0.4}$ 在 $(0,+\infty)$ 增，$0.4 > 0.2$ $\Rightarrow$ $0.4^{0.4} > 0.2^{0.4}$。

综合：$0.4^{0.2} > 0.4^{0.4} > 0.2^{0.4}$。

---

### 例 4（应用）

**题目：** 某窗框用 12 m 型材围成矩形（不计损耗），一边靠墙。求矩形面积最大时的尺寸及最大面积。

**解：**

设垂直于墙的边 $x$ m，$0 < x < 6$，平行于墙的边 $(12 - 2x)$ m。

$$S = x(12 - 2x) = -2x^2 + 12x = -2\left(x - 3\right)^2 + 18.$$

$x = 3$ 时 $S_{\max} = 18$ m²。垂直于墙 3 m，平行于墙 6 m。

## 三、本章复习题（40 min）

### A 组（基础）

**1.** 函数 $f(x) = \sqrt{4 - x^2} + \dfrac{1}{x+1}$ 的定义域为 ______。

**解：** $4-x^2 \ge 0 \Rightarrow -2 \le x \le 2$；$x+1 \ne 0 \Rightarrow x \ne -1$。  
定义域 $[-2,-1) \cup (-1,2]$。

**2.** 判断奇偶性：$f(x) = x^3 - x$，$g(x) = x^2 + |x|$。

**解：** $f(-x) = -x^3 + x = -(x^3 - x) = -f(x)$，奇函数。  
$g(-x) = x^2 + |-x| = x^2 + |x| = g(x)$，偶函数。

**3.** 幂函数 $y = x^{\alpha}$ 过点 $(-2, 4)$，求 $\alpha$。

**解：** $(-2)^\alpha = 4 = (-2)^2$，取 $\alpha = 2$（偶次幂，定义域可含负数）。

**4.** $f(x) = \begin{cases} x+1, & x<0 \\ x^2, & x \ge 0 \end{cases}$，求 $f(-2) + f(2)$。

**解：** $f(-2) = -1$，$f(2) = 4$，和为 **3**。

**5.** 二次函数 $y = -x^2 + 4x$ 在 $[0, 3]$ 上的最大值为 ______。

**解：** $y = -(x-2)^2 + 4$，对称轴 $x=2 \in [0,3]$，最大值 **4**。

---

### B 组（综合）

**6.** 用定义法证明 $f(x) = x + \sqrt{x}$ 在 $[0, +\infty)$ 上单调递增。

**解：**

设 $0 \le x_1 < x_2$，则

$$f(x_2) - f(x_1) = (x_2 - x_1) + (\sqrt{x_2} - \sqrt{x_1}) = (x_2 - x_1) + \dfrac{x_2 - x_1}{\sqrt{x_2} + \sqrt{x_1}} > 0.$$

故 $f(x_2) > f(x_1)$，$f$ 在 $[0,+\infty)$ 上单调递增。

**7.** 若 $f(x)$ 为偶函数且在 $[0,+\infty)$ 上减，比较 $f(-3)$、$f(1)$、$f(2)$ 的大小。

**解：** $f(-3) = f(3)$。在 $[0,+\infty)$ 减，$f(3) < f(2) < f(1)$。  
故 $f(-3) < f(2) < f(1)$。

**8.** 某商品售价 $p$ 元时销量 $Q = 1000 - 20p$ 件（$p$ 为正整数），成本每件 20 元。求利润最大时的售价。

**解：** 利润 $L = (p-20)(1000-20p) = -20p^2 + 1400p - 20000$，$p$ 为正整数且 $Q>0$，$p < 50$。

对称轴 $p = 35$，$L_{\max}$ 在 $p = 35$ 时取得，售价 **35 元**。

**9.** 方程 $x^2 = |x|$ 的实数解个数为 ______，解为 ______。

**解：** $x^2 = |x|$ $\Rightarrow$ $|x|(|x|-1)=0$，$x = 0, \pm 1$，共 **3** 个。

**10.** **选做**：已知 $f(x+y) = f(x) + f(y)$ 对任意 $x,y \in \mathbb{R}$ 成立，且 $f(1) = 2$，求 $f(3)$。（提示：先求 $f(2)$）

**解：** $f(2) = f(1+1) = 2f(1) = 4$；$f(3) = f(2+1) = f(2)+f(1) = 6$。

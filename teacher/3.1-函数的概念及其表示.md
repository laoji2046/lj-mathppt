## 二、新知讲解（45 min）

> 📖 以下定义、表述均摘自教材 **§3.1**，与课本逐字一致（符号已转为 LaTeX）。

### 2.1 函数的概念（教材 P62）

一般地，设 $A$，$B$ 是**非空的实数集**，如果对于集合 $A$ 中的**任意一个**数 $x$，按照某种**确定的**对应关系 $f$，在集合 $B$ 中都有**唯一确定**的数 $y$ 和它对应，那么就称 $f: A \to B$ 为从集合 $A$ 到集合 $B$ 的一个**函数**（function），记作

$$y = f(x),\quad x \in A.$$

其中，$x$ 叫做**自变量**，$x$ 的取值范围 $A$ 叫做函数的**定义域**（domain）；与 $x$ 的值相对应的 $y$ 值叫做**函数值**，函数值的集合 $\{f(x) \mid x \in A\}$ 叫做函数的**值域**（range）。

显然，值域是集合 $B$ 的子集。

### 2.2 函数的构成要素与同一函数（教材 P66）

由函数的定义可知，一个函数的构成要素为：**定义域**、**对应关系**和**值域**。因为值域是由定义域和对应关系决定的，所以，如果两个函数的定义域相同，并且对应关系完全一致，即相同的自变量对应的函数值也相同，那么这两个函数是**同一个函数**。

### 2.3 区间（教材 P70–P71）

设 $a$，$b$ 是两个实数，而且 $a < b$。我们规定：

- 满足不等式 $a \le x \le b$ 的实数 $x$ 的集合叫做**闭区间**，表示为 $[a,b]$；
- 满足不等式 $a < x < b$ 的实数 $x$ 的集合叫做**开区间**，表示为 $(a,b)$；
- 满足不等式 $a \le x < b$ 或 $a < x \le b$ 的实数 $x$ 的集合叫做**半开半闭区间**，分别表示为 $[a,b)$，$(a,b]$。

这里的实数 $a$ 与 $b$ 都叫做相应区间的**端点**。

实数集 $\mathbb{R}$ 可以用区间表示为 $(-\infty, +\infty)$。

### 2.4 函数的三种表示法（教材 P73）

**解析法**，就是用数学表达式表示两个变量之间的对应关系。

**列表法**，就是列出表格来表示两个变量之间的对应关系。

**图象法**，就是用图象表示两个变量之间的对应关系。

### 2.5 分段函数（教材 P74）

像

$$y = \begin{cases} -x, & x < 0, \\ x, & x \ge 0 \end{cases}$$

这样的函数称为**分段函数**。

## 三、例题（40 min）

### 例 1（基础）

**题目：** 判断下列对应是否为 $A$ 到 $B$ 的函数；若是，写出定义域与值域。

（1）$A = \{1,2,3\}$，$B = \{4,5,6\}$，对应「$x$ 的 2 倍」；  
（2）$A = \mathbb{R}$，$B = \mathbb{R}$，$y = \sqrt{x-1}$；  
（3）$A = \mathbb{R}$，$B = \mathbb{R}$，$y^2 = x$。

**解：**

（1）是函数。$f(1)=2$ 不在 $B$ 中——若 $B$ 限定为 $\{2,4,6\}$ 则不是；按题 $B=\{4,5,6\}$，$1 \mapsto 2 \notin B$，**不是**从 $A$ 到给定 $B$ 的函数。  
（修正理解：若对应为 $1\to4, 2\to5, 3\to6$，则是函数，定义域 $A$，值域 $\{4,5,6\}$。）

按「$x$ 的 2 倍」且 $A=\{1,2,3\}$，像为 $\{2,4,6\}$。若 $B=\{4,5,6\}$，则 $2,4,6$ 不全在 $B$ 中，**不是**函数。  
若 $B=\{2,4,6\}$，则是函数，定义域 $\{1,2,3\}$，值域 $\{2,4,6\}$。

（2）是函数 $f(x)=\sqrt{x-1}$。定义域 $\{x \mid x \ge 1\} = [1,+\infty)$，值域 $[0,+\infty)$。

（3）不是函数。例如 $x=4$ 时，$y=\pm 2$，一个 $x$ 对应两个 $y$，违反唯一性。

---

### 例 2（综合）

**题目：** 求下列函数的定义域：

（1）$f(x) = \dfrac{1}{x-2} + \sqrt{x+1}$；  
（2）$f(x) = \sqrt{x^2 - 4} + \dfrac{1}{|x|-3}$。

**解：**

（1）需 $x-2 \ne 0$ 且 $x+1 \ge 0$，即 $x \ne 2$ 且 $x \ge -1$。  
定义域为 $\{x \mid x \ge -1 \text{ 且 } x \ne 2\} = [-1,2) \cup (2,+\infty)$。

（2）需 $x^2-4 \ge 0$ 且 $|x|-3 \ne 0$，即 $|x| \ge 2$ 且 $x \ne \pm 3$。  
定义域为 $(-\infty,-3) \cup (-3,-2] \cup [2,3) \cup (3,+\infty)$。

---

### 例 3（分段函数）

**题目：** 已知

$$f(x) = \begin{cases}
x + 2, & x < -1, \\
x^2, & -1 \le x < 2, \\
5 - x, & x \ge 2.
\end{cases}$$

（1）求 $f(-2)$，$f(-1)$，$f(1)$，$f(3)$；  
（2）若 $f(a) = 3$，求 $a$。

**解：**

（1）$f(-2) = -2 + 2 = 0$（用第一段）；  
$f(-1) = (-1)^2 = 1$（$-1 \le x < 2$）；  
$f(1) = 1^2 = 1$；  
$f(3) = 5 - 3 = 2$。

（2）分三种情况：

- $a < -1$：$a + 2 = 3 \Rightarrow a = 1$，与 $a < -1$ 矛盾，舍；
- $-1 \le a < 2$：$a^2 = 3 \Rightarrow a = \pm\sqrt{3}$，只有 $a = \sqrt{3} \in [-1,2)$ 成立；
- $a \ge 2$：$5 - a = 3 \Rightarrow a = 2$，成立。

故 $a = \sqrt{3}$ 或 $a = 2$。

## 五、易错点与小结（15 min）

### 易错点

| 错因 | 正解 |
|------|------|
| 只比较表达式，忽略定义域 | 同一函数须定义域、对应法则均相同 |
| 分段函数求值未判区间 | 先确定自变量落在哪一段 |
| 分式、根式复合求定义域漏条件 | 各类限制取**交集** |
| 把值域与 codomain 混淆 | 值域是实际取到的函数值集合 |

### 小结

- 函数本质：**定义域内任意 $x$ 有唯一 $f(x)$**
- 三要素：定义域、值域、对应法则
- 三种表示：解析法、图象法、列表法
- 分段函数：一个函数，分段写解析式

## 二、新知讲解（45 min）

> 📖 以下定义、表述均摘自教材 **§4.3**，与课本逐字一致（符号已转为 LaTeX）。

### 2.1 对数的定义（教材 P122）

**定义（教材 P122）：** 一般地，如果 $a^x = N$（$a > 0$，且 $a 
e 1$），那么数 $x$ 叫做以 $a$ 为底 $N$ 的**对数**（logarithm），记作

$$x = \log_a N,$$

其中 $a$ 叫做对数的**底数**，$N$ 叫做**真数**。

**常用对数与自然对数（教材 P122）：** 以 $10$ 为底的对数叫做**常用对数**（common logarithm），记 $\lg N = \log_{10} N$。以无理数 $e = 2.71828\ldots$ 为底的对数称为**自然对数**（natural logarithm），记 $\ln N = \log_e N$。

**指数与对数的关系（教材 P122）：** 当 $a > 0$，$a 
e 1$ 时，$a^x = N \Leftrightarrow x = \log_a N$。

**结论（教材 P122）：** 负数和 $0$ 没有对数；$\log_a 1 = 0$，$\log_a a = 1$。

### 2.2 对数的运算法则（教材 P130）

如果 $a > 0$，且 $a 
e 1$，$M > 0$，$N > 0$，那么

（1）$\log_a(MN) = \log_a M + \log_a N$；  
（2）$\log_a \dfrac{M}{N} = \log_a M - \log_a N$；  
（3）$\log_a M^n = n \log_a M$（$n \in \mathbb{R}$）。

### 2.3 换底公式（教材 P131）

$$\log_a b = \frac{\log_c b}{\log_c a} \quad (a > 0,\, a 
e 1;\, b > 0;\, c > 0,\, c 
e 1).$$

我们把这个公式叫做**对数换底公式**。

## 三、例题（40 min）

### 例 1（基础）

**题目：** 将下列指数式与对数式互化：

（1）$2^5 = 32$；（2）$\log_3 81 = 4$；（3）$e^2 = x$。

**解：**

（1）$2^5 = 32$ ⟺ $\log_2 32 = 5$  
（2）$\log_3 81 = 4$ ⟺ $3^4 = 81$  
（3）$e^2 = x$ ⟺ $\ln x = 2$，即 $x = e^2$

---

### 例 2（综合）

**题目：** 化简：

（1）$\lg 2 + \lg 5$；（2）$\log_2 8 + \log_2 \dfrac{1}{4}$；（3）$2\log_3 6 - \log_3 4$。

**解：**

（1）$\lg 2 + \lg 5 = \lg(2 \times 5) = \lg 10 = 1$

（2）$\log_2 8 + \log_2 \dfrac{1}{4} = \log_2 \left(8 \times \dfrac{1}{4}\right) = \log_2 2 = 1$

（3）$2\log_3 6 - \log_3 4 = \log_3 6^2 - \log_3 4 = \log_3 \dfrac{36}{4} = \log_3 9 = 2$

---

### 例 3（拓展）

**题目：** 已知 $\log_2 3 = a$，$\log_2 5 = b$，用 $a, b$ 表示 $\log_{30} 8$。

**解：**

$$\log_{30} 8 = \frac{\log_2 8}{\log_2 30} = \frac{3}{\log_2(2 \times 3 \times 5)} = \frac{3}{\log_2 2 + \log_2 3 + \log_2 5} = \frac{3}{1 + a + b}$$

## 五、易错点与小结（15 min）

### 易错点

| 错因 | 正解 |
|------|------|
| $\log_a(M + N) = \log_a M + \log_a N$ | 只有**积**才能拆成和 |
| 忽略真数大于 0 | $\log_2(-4)$ 无意义 |
| 换底公式分子分母颠倒 | $\log_a b = \dfrac{\log_c b}{\log_c a}$ |
| $\log_a a^2 = 2$ 未考虑 $a$ 的符号 | 在 $a > 0$ 前提下 $\log_a a^2 = 2$ |

### 小结

- **定义**：$a^x = N \Leftrightarrow x = \log_a N$（$a > 0$，$a \ne 1$，$N > 0$）
- **法则**：积→和、商→差、幂→乘
- **换底**：$\log_a b = \dfrac{\log_c b}{\log_c a}$

## 二、公式汇总（30 min）

> 📖 以下表述摘自教材 **第五章小结**（P253 附近），与课本一致。

### 2.1 本章知识结构（教材 P253）

本章利用函数的研究经验，学习刻画周期性变化规律的三角函数。从任意角、弧度制出发，借助单位圆定义三角函数，利用诱导公式、同角关系进行化简求值；研究正弦、余弦、正切函数的图象与性质（周期性、奇偶性、单调性、最值）；学习两角和差、二倍角等恒等变换；最后研究 $y = A\sin(\omega x + arphi)$ 的图象变换及三角函数在周期现象中的应用。

### 2.2 核心公式与概念（教材 P253）

- **弧度制：** $180° = \pi\,\text{rad}$，$l = |\alpha|r$，$S = \frac{1}{2}|\alpha|r^2$
- **定义：** $\sin\alpha = y$，$\cos\alpha = x$，$\tan\alpha = \dfrac{y}{x}$（单位圆）
- **诱导公式：** 奇变偶不变，符号看象限
- **和差角、二倍角公式**（见 §5.5）
- **$y = A\sin(\omega x + arphi)$：** 振幅 $|A|$，周期 $T = \dfrac{2\pi}{\omega}$，初相 $arphi$

### 2.3 复习思考题（教材 P253）

回顾三角函数的定义方法；单位圆的作用；图象与性质的研究过程；参数 $A, \omega, arphi$ 的意义；能否根据数据建立周期函数模型等。

## 三、复习例题（35 min）

### 例 1

已知 $\sin\alpha = \dfrac{1}{3}$，$\alpha \in \left(\dfrac{\pi}{2}, \pi\right)$，求 $\cos 2\alpha$、$\sin\left(\alpha - \dfrac{\pi}{4}\right)$。

**解：**

$\cos\alpha = -\dfrac{2\sqrt{2}}{3}$。

$$\cos 2\alpha = 1 - 2\sin^2\alpha = 1 - \frac{2}{9} = \frac{7}{9}.$$

$$\sin\left(\alpha - \frac{\pi}{4}\right) = \sin\alpha\cos\frac{\pi}{4} - \cos\alpha\sin\frac{\pi}{4} = \frac{1}{3}\cdot\frac{\sqrt{2}}{2} - \left(-\frac{2\sqrt{2}}{3}\right)\cdot\frac{\sqrt{2}}{2} = \frac{\sqrt{2} + 4}{6}.$$

---

### 例 2

求函数 $y = 2\sin\left(\dfrac{x}{3} + \dfrac{\pi}{6}\right)$ 的周期、单调递增区间（一个周期内）。

**解：**

$T = \dfrac{2\pi}{1/3} = 6\pi$。

令 $u = \dfrac{x}{3}+\dfrac{\pi}{6}$，$\sin u$ 递增当 $-\dfrac{\pi}{2}+2k\pi \le u \le \dfrac{\pi}{2}+2k\pi$。

$k=0$：$-\dfrac{\pi}{2} \le \dfrac{x}{3}+\dfrac{\pi}{6} \le \dfrac{\pi}{2}$，$-\dfrac{2\pi}{3} \le x \le \pi$。

---

### 例 3

化简：$\dfrac{\sin(\pi+\alpha)\cos(-\alpha)}{\tan(-\alpha)\sin(\pi/2+\alpha)}$。

**解：**

原式 $= \dfrac{(-\sin\alpha)\cos\alpha}{(-\tan\alpha)\cos\alpha} = \dfrac{\sin\alpha}{\tan\alpha} = \cos\alpha$（$\cos\alpha \ne 0$，$\tan\alpha \ne 0$）。

## 四、本章复习题（35 min）

### A 组·基础

**1.** 把 $-1125°$ 化为弧度，并在 $0 \sim 2\pi$ 内找终边相同的角。

**解：** $-1125° = -1125 \times \dfrac{\pi}{180} = -\dfrac{25\pi}{4}$；加 $4\pi$ 得 $\dfrac{7\pi}{4}$。

---

**2.** 若 $\tan\alpha = 3$，且 $\alpha$ 为第三象限角，求 $\sin\alpha$。

**解：** $\sin\alpha = -\dfrac{3}{\sqrt{10}} = -\dfrac{3\sqrt{10}}{10}$。

---

**3.** 求 $\sin 75° \cos 15° + \cos 75° \sin 15°$ 的值。

**解：** 原式 $= \sin(75°+15°) = \sin 90° = 1$。

---

**4.** 函数 $y = \tan\left(2x - \dfrac{\pi}{3}\right)$ 的最小正周期为 ______。

**解：** $T = \dfrac{\pi}{2}$。

---

**5.** 求 $y = \sin x + \cos x$ 的最大值。

**解：** $y = \sqrt{2}\sin\left(x+\dfrac{\pi}{4}\right)$，最大值 $\sqrt{2}$。

---

### B 组·综合

**6.** 已知 $f(x) = A\sin(\omega x + \varphi)$（$A>0$，$\omega>0$，$|\varphi|<\pi$）部分图象过 $\left(\dfrac{\pi}{12}, 3\right)$ 和 $\left(\dfrac{\pi}{3}, -3\right)$，求 $f(x)$。

**解：**

由值域得 $A=3$。半周期 $\dfrac{\pi}{3}-\dfrac{\pi}{12}=\dfrac{\pi}{4}$，$T=\dfrac{\pi}{2}$，$\omega=4$。

过 $\left(\dfrac{\pi}{12},3\right)$：$\sin\left(\dfrac{\pi}{3}+\varphi\right)=1$，$\varphi=\dfrac{\pi}{6}$。

$f(x) = 3\sin\left(4x + \dfrac{\pi}{6}\right)$。

---

**7.** 若 $\cos\alpha + \sin\alpha = \dfrac{1}{2}$，求 $\sin 2\alpha$。

**解：** 两边平方：$1 + \sin 2\alpha = \dfrac{1}{4}$，$\sin 2\alpha = -\dfrac{3}{4}$。

---

**8.** 某简谐振动 $s = 2\sin\left(\pi t + \dfrac{\pi}{6}\right)$，求 $t=2$ 时的位移及首次到达最大位移的时刻（$t \ge 0$）。

**解：** $t=2$：$s = 2\sin\left(2\pi+\dfrac{\pi}{6}\right) = 2\sin\dfrac{\pi}{6} = 1$。

$\pi t + \dfrac{\pi}{6} = \dfrac{\pi}{2}$，$t = \dfrac{1}{3}$（s）。

---

### C 组·选做

**9.** 求证：$\tan\alpha + \tan\beta = \dfrac{\sin(\alpha+\beta)}{\cos\alpha\cos\beta}$。

**解：**

$$\frac{\sin(\alpha+\beta)}{\cos\alpha\cos\beta} = \frac{\sin\alpha\cos\beta + \cos\alpha\sin\beta}{\cos\alpha\cos\beta} = \tan\alpha + \tan\beta.$$

---

**10.** 求函数 $y = \sin^2 x + \sin 2x$ 的最小正周期及值域。

**解：**

$y = \dfrac{1-\cos 2x}{2} + \sin 2x = \dfrac{1}{2} - \dfrac{1}{2}\cos 2x + \sin 2x$。

可化为 $\sqrt{2}\sin\left(2x - \dfrac{\pi}{4}\right) + \dfrac{1}{2}$，周期 $\pi$，值域 $\left[\dfrac{1}{2}-\dfrac{\sqrt{2}}{2},\, \dfrac{1}{2}+\dfrac{\sqrt{2}}{2}\right]$。

## 五、易错点回顾

| 章节 | 常见错误 |
|------|----------|
| 5.1 | 弧长公式用角度制；象限判断未化角 |
| 5.2 | $\tan\alpha = y/x$ 记反；开方忘看象限 |
| 5.3 | 诱导公式符号看错象限 |
| 5.4 | $\tan x$ 周期误为 $2\pi$ |
| 5.5 | 和角公式符号；辅助角 $\varphi$ 象限 |
| 5.6 | 平移量应为 $\varphi/\omega$ |
| 5.7 | 模型中 $k$ 与 $A$ 混淆 |

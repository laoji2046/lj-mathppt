# §2.1 等式性质与不等式性质

> **教材位置**：第二章 · §2.1 等式性质与不等式性质  
> **建议时长**：约 120 min（2 h）  
> **前置知识**：实数运算、一元一次方程与不等式、作差比较大小（初中）

---

## 本节目标

1. 会用**作差法**比较两个实数（式）的大小，理解 $a - b > 0 \Leftrightarrow a > b$；
2. 掌握不等式的基本性质（对称性、传递性、可加性、可乘性等），能进行简单变形与证明；
3. 理解「大于」「小于」与实数在数轴上位置的关系，能利用性质解决比较大小与证明问题。

## 二、新知讲解（45 min）

> 📖 以下定义、表述均摘自教材 **§2.1**，与课本逐字一致（符号已转为 LaTeX）。

### 2.1 两个实数大小关系的基本事实（教材 P38）

关于实数 $a$，$b$ 大小的比较，有以下基本事实：

如果 $a-b$ 是正数，那么 $a > b$；如果 $a-b$ 等于 $0$，那么 $a = b$；如果 $a-b$ 是负数，那么 $a < b$。**反过来也对**。

这个基本事实可以表示为

$$a > b \Leftrightarrow a - b > 0;\quad a = b \Leftrightarrow a - b = 0;\quad a < b \Leftrightarrow a - b < 0.$$

从上述基本事实可知，要比较两个实数的大小，可以转化为比较它们的差与 $0$ 的大小。

### 2.2 重要不等式（教材 P39）

一般地，$\forall a,b \in \mathbb{R}$，有

$$a^2 + b^2 \ge 2ab,$$

当且仅当 $a = b$ 时，等号成立。

### 2.3 等式的基本性质（教材 P40）

| 性质 | 内容 |
|------|------|
| 性质 1 | 如果 $a = b$，那么 $b = a$ |
| 性质 2 | 如果 $a = b$，$b = c$，那么 $a = c$ |
| 性质 3 | 如果 $a = b$，那么 $a \pm c = b \pm c$ |
| 性质 4 | 如果 $a = b$，那么 $ac = bc$ |
| 性质 5 | 如果 $a = b$，$c \ne 0$，那么 $\dfrac{a}{c} = \dfrac{b}{c}$ |

### 2.4 不等式的基本性质（教材 P41–P42）

**性质 1（对称性）：** 如果 $a > b$，那么 $b < a$；如果 $b < a$，那么 $a > b$。即

$$a > b \Leftrightarrow b < a.$$

**性质 2（传递性）：** 如果 $a > b$，$b > c$，那么 $a > c$。即

$$a > b,\, b > c \Rightarrow a > c.$$

**性质 3（可加性）：** 如果 $a > b$，那么 $a + c > b + c$。

这就是说，不等式的两边都加上同一个实数，所得不等式与原不等式**同向**。

由性质 3 可得，$a + b > c \Leftrightarrow a + b + (-b) > c + (-b) \Leftrightarrow a > c - b$。这表明，不等式中任何一项可以改变符号后移到不等号的另一边。

**性质 4（可乘性）：** 如果 $a > b$，$c > 0$，那么 $ac > bc$；如果 $a > b$，$c < 0$，那么 $ac < bc$。

这就是说，不等式两边同乘一个正数，所得不等式与原不等式同向；不等式两边同乘一个负数，所得不等式与原不等式**反向**。

**性质 5：** 如果 $a > b$，$c > d$，那么 $a + c > b + d$。

**性质 6：** 如果 $a > b > 0$，$c > d > 0$，那么 $ac > bd$。

**性质 7：** 如果 $a > b > 0$，那么 $a^n > b^n$（$n \in \mathbb{N}$，$n \ge 2$）。

实数大小关系的基本事实和不等式的性质是解决不等式问题的基本依据。

## 三、例题（40 min）

### 例 1（基础·作差法）

**题目：** 已知 $a,b \in \mathbb{R}$，比较 $a^2 + b^2 + 2$ 与 $2a + 2b$ 的大小。

**解：**

作差：
$$
\begin{aligned}
&(a^2 + b^2 + 2) - (2a + 2b) \\
&= a^2 - 2a + 1 + b^2 - 2b + 1 \\
&= (a-1)^2 + (b-1)^2 \ge 0
\end{aligned}
$$

当且仅当 $a = 1$ 且 $b = 1$ 时取等号。

故 $a^2 + b^2 + 2 \ge 2a + 2b$，即 **$a^2 + b^2 + 2 \ge 2a + 2b$**。

---

### 例 2（综合·性质应用）

**题目：** 若 $a > b > 0$，$c < 0$，判断下列各式正误并说明理由：

（1）$a + c > b + c$；（2）$ac > bc$；（3）$\dfrac{1}{a} < \dfrac{1}{b}$；（4）$a^2 > b^2$。

**解：**

（1）**正确**。$a > b$，两边同加 $c$，不等号方向不变。

（2）**错误**。$a > b$，$c < 0$，两边同乘负数，得 $ac < bc$。

（3）**正确**。$a > b > 0$，取倒数（正数，方向变）：$\dfrac{1}{a} < \dfrac{1}{b}$。

（4）**正确**。$a > b > 0$，同向正数可乘，$a^2 > b^2$。

---

### 例 3（拓展·证明）

**题目：** 已知 $x,y \in \mathbb{R}$，求证：$x^2 + y^2 \ge 2xy$，并说明等号成立条件。

**解：**

作差：
$$
x^2 + y^2 - 2xy = (x - y)^2 \ge 0
$$

故 $x^2 + y^2 \ge 2xy$，当且仅当 $x = y$ 时等号成立。

> **课堂提示**：此式即基本不等式的代数形式，为 §2.2 铺垫。

## 四、课堂练习（25 min）

1. 用作差法比较 $x^2 + 1$ 与 $2x$ 的大小。

2. 若 $a > b$，$c < 0$，则下列正确的是（  ）  
   A. $a + c > b + c$  B. $ac > bc$  C. $\dfrac{a}{c} > \dfrac{b}{c}$  D. $a - c < b - c$

3. 已知 $1 < a < 3$，$-2 < b < -1$，求 $a + b$、$ab$ 的取值范围。

4. 证明：若 $a > b > 0$，则 $a^3 > b^3$。

5. **思考**：$a > b$ 能否推出 $a^2 > b^2$？举反例说明。

## 五、易错点与小结（15 min）

### 易错点

| 错因 | 正解 |
|------|------|
| 两边同乘负数忘记变号 | $a > b$，$c < 0$ 时 $ac < bc$ |
| 认为 $a > b$ 则 $a^2 > b^2$ | 需考虑符号，如 $-1 > -2$ 但 $1 < 4$ |
| 作差后符号判断失误 | 配方、因式分解要完整，注意「$\ge 0$」与「$> 0$」 |
| 传递性乱用 | 中间量 $b$ 必须满足 $a > b$ 且 $b > c$ 的链式关系 |

### 小结

- **作差法**：$a - b$ 与 0 比较，是比较大小的基本方法
- **核心性质**：对称、传递、可加、可乘（注意乘数符号）
- 证明不等式常用：作差、配方、利用已知性质链式推导

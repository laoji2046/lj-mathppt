## 一、复习引入（15 min）

**复习提问：**

- 观察 $y = x$ 与 $y = -x + 3$ 的图象：从左向右看，图象是「上升」还是「下降」？
- $y = x^2$ 的图象关于哪条直线对称？$y = x^3$ 呢？

**情境：**

> 比较 $f(2)$ 与 $f(5)$ 的大小时，若知道函数在区间上「越来越大」，就不必逐点计算——这就是**单调性**；若知道图象关于 $y$ 轴对称，则 $f(-2)=f(2)$——这就是**奇偶性**。

## 二、新知讲解（45 min）

> 📖 以下定义、表述均摘自教材 **§3.2**，与课本逐字一致（符号已转为 LaTeX）。

### 2.1 单调性（教材 P77）

在初中，我们利用函数图象研究过函数值随自变量的增大而增大（或减小）的性质，这一性质叫做函数的**单调性**。

一般地，设函数 $f(x)$ 的定义域为 $I$，区间 $D \subseteq I$：

如果 $\forall x_1, x_2 \in D$，当 $x_1 < x_2$ 时，都有 $f(x_1) < f(x_2)$，那么就称函数 $f(x)$ 在区间 $D$ 上**单调递增**。

特别地，当函数 $f(x)$ 在它的定义域上单调递增时，我们就称它是**增函数**（increasing function）。

如果 $\forall x_1, x_2 \in D$，当 $x_1 < x_2$ 时，都有 $f(x_1) > f(x_2)$，那么就称函数 $f(x)$ 在区间 $D$ 上**单调递减**。

特别地，当函数 $f(x)$ 在它的定义域上单调递减时，我们就称它是**减函数**（decreasing function）。

如果函数 $y = f(x)$ 在区间 $D$ 上单调递增或单调递减，那么就说函数 $y = f(x)$ 在这一区间具有（严格的）**单调性**，区间 $D$ 叫做 $y = f(x)$ 的**单调区间**。

### 2.2 最大值（教材 P80）

一般地，设函数 $y = f(x)$ 的定义域为 $I$，如果存在实数 $M$ 满足：

（1）$\forall x \in I$，都有 $f(x) \le M$；

（2）$\exists x_0 \in I$，使得 $f(x_0) = M$。

那么，我们称 $M$ 是函数 $y = f(x)$ 的**最大值**（maximum value）。

当一个函数 $f(x)$ 的图象有最低点时，我们就说函数 $f(x)$ 有**最小值**。

### 2.3 奇偶性（教材 P83–P84）

**偶函数：** 一般地，设函数 $f(x)$ 的定义域为 $I$，如果 $\forall x \in I$，都有 $-x \in I$，且 $f(-x) = f(x)$，那么函数 $f(x)$ 就叫做**偶函数**（even function）。

**奇函数：** 一般地，设函数 $f(x)$ 的定义域为 $I$，如果 $\forall x \in I$，都有 $-x \in I$，且 $f(-x) = -f(x)$，那么函数 $f(x)$ 就叫做**奇函数**（odd function）。

> **说明：** 奇偶性是函数在它的定义域上的整体性质，所以判断函数的奇偶性应先明确它的定义域。

## 三、例题（40 min）

### 例 1（定义法证单调性）

**题目：** 用定义证明 $f(x) = x + \dfrac{1}{x}$ 在 $(0, 1]$ 上单调递减。

**解：**

设 $0 < x_1 < x_2 \le 1$，则

$$f(x_1) - f(x_2) = \left(x_1 + \frac{1}{x_1}\right) - \left(x_2 + \frac{1}{x_2}\right) = (x_1 - x_2) + \frac{x_2 - x_1}{x_1 x_2} = (x_1 - x_2)\left(1 - \frac{1}{x_1 x_2}\right).$$

由 $0 < x_1 < x_2 \le 1$，得 $x_1 - x_2 < 0$，$0 < x_1 x_2 < 1$，故 $1 - \dfrac{1}{x_1 x_2} < 0$。

所以 $f(x_1) - f(x_2) > 0$，即 $f(x_1) > f(x_2)$。

故 $f(x)$ 在 $(0, 1]$ 上单调递减。

---

### 例 2（奇偶性）

**题目：** 判断下列函数的奇偶性：

（1）$f(x) = x^3 + x$；  
（2）$f(x) = x^2 + 1$；  
（3）$f(x) = \dfrac{x^2}{x}$；  
（4）$f(x) = \sqrt{1 - x^2}$。

**解：**

（1）定义域 $\mathbb{R}$。$f(-x) = (-x)^3 + (-x) = -x^3 - x = -(x^3 + x) = -f(x)$，**奇函数**。

（2）定义域 $\mathbb{R}$。$f(-x) = (-x)^2 + 1 = x^2 + 1 = f(x)$，**偶函数**。

（3）$f(x) = x$（$x \ne 0$），定义域 $\{x \mid x \ne 0\}$，关于原点对称。$f(-x) = -x = -f(x)$，**奇函数**。

（4）定义域 $[-1, 1]$，关于原点对称。$f(-x) = \sqrt{1 - (-x)^2} = \sqrt{1 - x^2} = f(x)$，**偶函数**。

---

### 例 3（综合）

**题目：** 已知 $f(x)$ 是 $\mathbb{R}$ 上的奇函数，在 $(-\infty, 0]$ 上单调递增，且 $f(2) = -1$，比较 $f(-3)$、$f(0)$、$f(4)$ 的大小。

**解：**

由奇函数：$f(-3) = -f(3)$，$f(4) = -f(-4)$。

在 $(-\infty, 0]$ 上增，$-4 < -3 < 0$，故 $f(-4) < f(-3) \le f(0)$。

$f(3) = -f(-3)$，$f(4) = -f(-4)$。

由 $f(-4) < f(-3)$，两边取负（不等号反向）：$-f(-4) > -f(-3)$，即 $f(4) > f(3)$。

又 $f(3) = -f(-3)$，$f(-3) \le f(0)$，且 $f(0)=0$（奇函数），得 $f(-3) \le 0$。

在 $(0,+\infty)$ 上，奇函数与 $(-\infty,0)$ 单调性相同，故在 $(0,+\infty)$ 上也增，$f(3) < f(4)$。

综合：$f(-3) = -f(3)$，$f(3) < f(4)$，$f(-3) \le f(0)=0$。

具体数值：$f(2)=-1$，由奇 $f(-2)=1$；在 $(-\infty,0]$ 增，$f(-3) < f(-2)=1$，故 $f(-3) < 1$；$f(-3) = -f(3)$。

更直接：$(-\infty,0]$ 增 $\Rightarrow$ $f(-4) < f(-3) < f(0)=0$；奇 $\Rightarrow$ $f(4)=-f(-4)$，$f(3)=-f(-3)$；$(0,+\infty)$ 增 $\Rightarrow$ $f(3) < f(4)$。

大小关系：**$f(-3) < f(0) < f(4)$**（且 $f(3) = -f(-3) > 0$）。

## 五、易错点与小结（15 min）

### 易错点

| 错因 | 正解 |
|------|------|
| 证明单调性未设 $x_1<x_2$ | 严格按定义，作差判符号 |
| 写 $y=\frac{1}{x}$ 在 $(-\infty,0)\cup(0,+\infty)$ 减 | 并区间上不能说单调，须分开写 |
| 不先看定义域对称就判奇偶 | 定义域须关于原点对称 |
| 奇函数忽略 $f(0)=0$ | $0$ 在定义域内则 $f(0)=0$ |

### 小结

- **单调性**：区间上 $x$ 增大时 $f(x)$ 的变化趋势；定义法四步：设元、作差、变形、定号
- **奇偶性**：$f(-x)$ 与 $f(x)$、$-f(x)$ 的关系；图象对称
- **综合**：先奇偶转化到已知区间，再用单调性

## 二、新知讲解（45 min）

> 📖 以下公式均摘自教材 **§5.5**，与课本逐字一致（符号已转为 LaTeX）。

### 2.1 两角和与差的余弦公式（教材 P215–P217）

**公式（教材 P217）：**

$$\cos(\alpha - \beta) = \cos \alpha \cos \beta + \sin \alpha \sin \beta \quad \text{（$C_{(\alpha-\beta)}$）}$$

$$\cos(\alpha + \beta) = \cos \alpha \cos \beta - \sin \alpha \sin \beta \quad \text{（$C_{(\alpha+\beta)}$）}$$

### 2.2 两角和与差的正弦、正切公式（教材 P218–P220）

**正弦（教材 P218–P219）：**

$$\sin(\alpha + \beta) = \sin \alpha \cos \beta + \cos \alpha \sin \beta \quad \text{（$S_{(\alpha+\beta)}$）}$$

$$\sin(\alpha - \beta) = \sin \alpha \cos \beta - \cos \alpha \sin \beta \quad \text{（$S_{(\alpha-\beta)}$）}$$

**正切（教材 P220）：**

$$\tan(\alpha + \beta) = \frac{\tan \alpha + \tan \beta}{1 - \tan \alpha \tan \beta} \quad \text{（$T_{(\alpha+\beta)}$）}$$

$$\tan(\alpha - \beta) = \frac{\tan \alpha - \tan \beta}{1 + \tan \alpha \tan \beta} \quad \text{（$T_{(\alpha-\beta)}$）}$$

### 2.3 二倍角公式（教材 P221–P222）

$$\sin 2\alpha = 2\sin \alpha \cos \alpha \quad \text{（$S_{2\alpha}$）}$$

$$\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha = 2\cos^2 \alpha - 1 = 1 - 2\sin^2 \alpha \quad \text{（$C_{2\alpha}$）}$$

$$\tan 2\alpha = \frac{2\tan \alpha}{1 - \tan^2 \alpha} \quad \text{（$T_{2\alpha}$）}$$

### 2.4 辅助角公式（教材 P224）

$$a\sin x + b\cos x = \sqrt{a^2 + b^2}\sin(x + arphi)$$

其中 $\tan arphi = \dfrac{b}{a}$（需根据 $a, b$ 符号确定象限）。

## 三、例题（40 min）

### 例 1（基础）

**题目：** 已知 $\sin\alpha = \dfrac{3}{5}$，$\alpha \in \left(\dfrac{\pi}{2}, \pi\right)$，$\cos\beta = -\dfrac{5}{13}$，$\beta \in \left(\dfrac{\pi}{2}, \pi\right)$，求 $\sin(\alpha + \beta)$。

**解：**

$\cos\alpha = -\dfrac{4}{5}$，$\sin\beta = \dfrac{12}{13}$。

$$\sin(\alpha+\beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta = \frac{3}{5}\cdot\left(-\frac{5}{13}\right) + \left(-\frac{4}{5}\right)\cdot\frac{12}{13} = -\frac{63}{65}.$$

---

### 例 2（综合）

**题目：** 化简：$\dfrac{\sin 2\alpha}{1 + \cos 2\alpha}$。

**解：**

$$\frac{\sin 2\alpha}{1 + \cos 2\alpha} = \frac{2\sin\alpha\cos\alpha}{2\cos^2\alpha} = \tan\alpha \quad (\cos\alpha \ne 0).$$

---

### 例 3（综合）

**题目：** 求函数 $y = \sin x + \sqrt{3}\cos x$ 的最大值、最小值及取得最大值时 $x$ 的集合。

**解：**

$$y = 2\left(\frac{1}{2}\sin x + \frac{\sqrt{3}}{2}\cos x\right) = 2\sin\left(x + \frac{\pi}{3}\right).$$

最大值 $2$（$x + \dfrac{\pi}{3} = \dfrac{\pi}{2}+2k\pi$），即 $x = \dfrac{\pi}{6}+2k\pi$；

最小值 $-2$（$x = -\dfrac{5\pi}{6}+2k\pi$）。

---

### 例 4（拓展）

**题目：** 求证：$\dfrac{1 - \tan\theta}{1 + \tan\theta} = \tan\left(\dfrac{\pi}{4} - \theta\right)$。

**解：**

$$\tan\left(\frac{\pi}{4}-\theta\right) = \frac{\tan\frac{\pi}{4} - \tan\theta}{1 + \tan\frac{\pi}{4}\tan\theta} = \frac{1 - \tan\theta}{1 + \tan\theta}.$$

## 五、易错点与小结（15 min）

### 易错点

| 错因 | 正解 |
|------|------|
| 和角公式符号记反 | cos：同名积，$\alpha+\beta$ 用减号连接 sin 积 |
| 二倍角中 $\cos 2\alpha$ 三种形式选错 | 看已知是 $\sin\alpha$ 还是 $\cos\alpha$ 选形式 |
| 辅助角 $\varphi$ 象限定错 | 由 $a$、$b$ 符号确定 $\sin(x+\varphi)$ 中 $\varphi$ |
| $\tan(\alpha+\beta)$ 分母为 0 未排除 | 注明 $\alpha+\beta \ne \dfrac{\pi}{2}+k\pi$ |

### 小结

- 和差角：$\cos$、$\sin$、$\tan$ 三组公式
- 二倍角：$\sin 2\alpha$、$\cos 2\alpha$、$\tan 2\alpha$；降幂公式
- 辅助角：$a\sin x + b\cos x \to \sqrt{a^2+b^2}\sin(x+\varphi)$

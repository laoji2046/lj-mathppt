## 一、知识网络梳理（30 min）

### 1.1 指数与对数

```
根式 ↔ 分数指数幂（a > 0）
    ↓
有理数指数幂运算法则
    ↓
指数函数 y = a^x  ←——反函数——→  对数函数 y = log_a x
    ↓                              ↓
对数定义 a^x = N ⟺ x = log_a N
    ↓
对数运算法则 + 换底公式
```

### 1.2 核心公式汇总

**指数运算法则**（$a, b > 0$，$m, n \in \mathbb{Q}$）：

- $a^m \cdot a^n = a^{m+n}$；$\dfrac{a^m}{a^n} = a^{m-n}$；$(a^m)^n = a^{mn}$；$(ab)^n = a^n b^n$
- $a^{\frac{m}{n}} = \sqrt[n]{a^m}$；$a^{-\frac{m}{n}} = \dfrac{1}{a^{\frac{m}{n}}}$

**对数运算法则**（$M, N > 0$）：

- $\log_a(MN) = \log_a M + \log_a N$
- $\log_a \dfrac{M}{N} = \log_a M - \log_a N$
- $\log_a M^k = k \log_a M$
- **换底**：$\log_a b = \dfrac{\log_c b}{\log_c a}$

**恒等式：**

- $a^{\log_a N} = N$（$N > 0$）；$\log_a a^x = x$（$x \in \mathbb{R}$）

### 1.3 指数函数与对数函数对照

| 项目 | $y = a^x$（$a>0$，$a \ne 1$） | $y = \log_a x$ |
|------|-------------------------------|----------------|
| 定义域 | $\mathbb{R}$ | $(0, +\infty)$ |
| 值域 | $(0, +\infty)$ | $\mathbb{R}$ |
| 定点 | $(0, 1)$ | $(1, 0)$ |
| $a > 1$ | 递增 | 递增 |
| $0 < a < 1$ | 递减 | 递减 |
| 渐近线 | $y = 0$（$x$ 轴） | $x = 0$（$y$ 轴） |
| 关系 | 互为反函数，图象关于 $y = x$ 对称 | 同左 |

### 1.4 函数应用要点

- **零点**：$f(x) = 0$ 的实根；零点存在定理（连续 + 异号）
- **二分法**：求方程近似解
- **增长模型**：$\log_a x \ll kx \ll a^x$（$x$ 充分大）
- **建模步骤**：理解 → 假设 → 建立 → 求解 → 检验

### 2.1 本章知识结构（教材 P158）

本章我们先将指数概念由整数指数逐步拓展到了实数指数，并给出了实数指数幂的运算法则；通过对指数增长方式的实例分析，引入指数函数的概念，并研究了它的图象和性质。从对数与指数的相互联系出发，引入对数的概念，研究了对数的运算法则；在此基础上研究了对数函数的概念、图象和性质。指数函数和对数函数是两种不同类型但联系紧密的函数模型，是刻画客观世界中"指数爆炸""对数增长"现象的重要数学模型。利用函数零点与方程解之间的关系，我们引入了函数零点存在定理，探索了用二分法求方程近似解的思路。二分法是求方程近似解的一般性方法。不同类型的函数具有不同的增长方式，通过比较，我们认识了对数函数、线性函数、指数函数增长速度的差异，并通过了具体实例，学习了如何根据增长速度的差异，选择合适的函数类型构建数学模型、刻画现实问题变化规律的方法。

本章中，先从整数指数拓展到有理数指数，再利用有理数指数幂逼近无理数指数幂的思想认识无理数指数幂，从而将指数的概念拓展到实数指数；通过问题"在 $a^x = N$（$a > 0$，且 $a

## 三、复习例题（40 min）

### 例 1（基础）

**题目：** 化简 $\dfrac{a^{\frac{1}{2}} b^{-3}}{\sqrt{a b^{-1}}}$（$a, b > 0$）。

**解：**

原式 $= \dfrac{a^{\frac{1}{2}} b^{-3}}{a^{\frac{1}{2}} b^{-\frac{1}{2}}} = b^{-3 - (-\frac{1}{2})} = b^{-\frac{5}{2}} = \dfrac{1}{b^{\frac{5}{2}}}$

---

### 例 2（综合）

**题目：** 已知 $f(x) = 2^x$，$g(x) = \log_2 x$。  
（1）求 $f(g(8))$、$g(f(-1))$ 的值并解释为何 $g(f(-1))$ 无意义；  
（2）若 $f(m) = g(n)$，求 $m, n$ 的关系。

**解：**

（1）$f(g(8)) = f(\log_2 8) = f(3) = 2^3 = 8$（符合 $f(g(x)) = x$）

$g(f(-1)) = g(2^{-1}) = g(\dfrac{1}{2}) = \log_2 \dfrac{1}{2} = -1$

注：$f(-1) = \dfrac{1}{2} > 0$，$g(f(-1))$ **有意义**，值为 $-1$。  
（若题目改为 $g(f(0))$，则 $f(0) = 1$，$g(1) = 0$。）

（2）$2^m = \log_2 n$。由 $2^m = t > 0$，得 $\log_2 n = t$，即 $n = 2^t = 2^{2^m}$。

---

### 例 3（拓展）

**题目：** 求不等式 $\log_{\frac{1}{2}}(x^2 - 3x + 2) > 1$ 的解集。

**解：**

真数 $x^2 - 3x + 2 > 0$，即 $(x-1)(x-2) > 0$，故 $x < 1$ 或 $x > 2$。

底数 $0 < \dfrac{1}{2} < 1$，不等式 $\log_{\frac{1}{2}} M > 1$ 等价于 $0 < M < \dfrac{1}{2}$（递减，方向反转）。

$$0 < x^2 - 3x + 2 < \dfrac{1}{2}$$

先解 $x^2 - 3x + 2 > 0$：$x < 1$ 或 $x > 2$。

再解 $x^2 - 3x + 2 < \dfrac{1}{2}$，即 $x^2 - 3x + \dfrac{3}{2} < 0$，

判别式 $\Delta = 9 - 6 = 3$，根为 $x = \dfrac{3 \pm \sqrt{3}}{2}$。

故 $\dfrac{3 - \sqrt{3}}{2} < x < \dfrac{3 + \sqrt{3}}{2}$。

取交集：$\dfrac{3 - \sqrt{3}}{2} < x < 1$ 或 $2 < x < \dfrac{3 + \sqrt{3}}{2}$。

## 四、本章复习题（30 min）

### A 组（基础）

1. 计算：$27^{\frac{2}{3}} - 16^{\frac{1}{4}} + \left(\dfrac{1}{8}\right)^{-\frac{2}{3}}$。

### B 组（综合）

   实际上 $\lg 25 + \lg 4 = 2$，$\lg 5 + \lg 2 = 1$，若原题为 $\lg 25 + \lg 4 + \lg 2 = 3$。  
   按 $\lg 25 + \lg 4 + \lg 5$：$= \lg 100 + \lg 5 = 2 + \lg 5 \approx 2.699$

3. $(\dfrac{1}{2}, +\infty)$

4. $<$；$>$

5. B（$f(1) = -1$，$f(2) = 1$）

### B 组

6. $4^{x+1} = 4 \cdot (2^x)^2 = 4 \times 9 = 36$；$8^{-\frac{1}{3}} = \dfrac{1}{2}$；和为 $36.5$

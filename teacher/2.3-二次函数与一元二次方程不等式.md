## 二、新知讲解（45 min）

> 📖 以下定义、表述均摘自教材 **§2.3**，与课本逐字一致（符号已转为 LaTeX）。

### 2.1 一元二次不等式（教材 P50）

一般地，我们把只含有一个未知数，并且未知数的最高次数是 $2$ 的不等式，称为**一元二次不等式**（quadratic inequality in one unknown）。一元二次不等式的一般形式是

$$ax^2 + bx + c > 0 \quad \text{或} \quad ax^2 + bx + c < 0,$$

其中 $a$，$b$，$c$ 均为常数，$a \ne 0$。

### 2.2 二次函数的零点（教材 P50–P51）

对于二次函数 $y = ax^2 + bx + c$，我们把使 $ax^2 + bx + c = 0$ 的实数 $x$ 叫做二次函数 $y = ax^2 + bx + c$ 的**零点**。

**三个二次的联系：** 一元二次方程的根是相应一元二次函数的零点；二次函数图象与 $x$ 轴交点的横坐标就是方程的实数根；一元二次不等式的解集与二次函数图象在 $x$ 轴上方或下方的 $x$ 的取值范围相对应。

### 2.3 判别式 $\Delta$ 与解集（教材 P51，表 2.3-1）

对于一元二次方程 $ax^2 + bx + c = 0$（$a > 0$），设 $\Delta = b^2 - 4ac$，它的根按照 $\Delta > 0$，$\Delta = 0$，$\Delta < 0$ 可分为三种情况。相应地，二次函数 $y = ax^2 + bx + c$（$a > 0$）的图象与 $x$ 轴的位置关系也分为三种情况。因此，我们分三种情况来讨论对应的一元二次不等式 $ax^2 + bx + c > 0$（$a > 0$）和 $ax^2 + bx + c < 0$（$a > 0$）的解集。

| $\Delta$ | 方程 $ax^2+bx+c=0$（$a>0$）的根 | $ax^2+bx+c > 0$ 的解集 | $ax^2+bx+c < 0$ 的解集 |
|----------|----------------------------------|------------------------|------------------------|
| $\Delta > 0$ | 两个不相等的实数根 $x_1$，$x_2$（$x_1 < x_2$） | $\{x \mid x < x_1 \text{，或} x > x_2\}$ | $\{x \mid x_1 < x < x_2\}$ |
| $\Delta = 0$ | 两个相等的实数根 $x_1 = x_2 = -\dfrac{b}{2a}$ | $\{x \mid x \ne -\dfrac{b}{2a}\}$ | $\varnothing$ |
| $\Delta < 0$ | 没有实数根 | $\mathbb{R}$ | $\varnothing$ |

### 2.4 二次项系数为负数的情形（教材 P52）

对于二次项系数是负数（即 $a < 0$）的不等式，可以先把二次项系数化成正数，再求解。

### 2.5 求一元二次不等式解集的一般思路（教材 P52）

先求出一元二次方程的根，再根据二次函数图象与 $x$ 轴的相关位置确定一元二次不等式的解集。

## 三、例题（40 min）

### 例 1（基础·图象法）

**题目：** 解不等式 $x^2 - 2x - 3 \ge 0$。

**解：**

方程 $x^2 - 2x - 3 = 0$，$(x-3)(x+1) = 0$，得 $x_1 = -1$，$x_2 = 3$。

$a = 1 > 0$，开口向上。「大于取两边」：

**解集为 $(-\infty, -1] \cup [3, +\infty)$**。

---

### 例 2（综合·先化标准形）

**题目：** 解不等式 $-2x^2 + 3x + 2 > 0$。

**解：**

两边乘 $-1$（变号）：$2x^2 - 3x - 2 < 0$。

方程 $2x^2 - 3x - 2 = 0$，$(2x+1)(x-2) = 0$，$x_1 = -\dfrac{1}{2}$，$x_2 = 2$。

$a = 2 > 0$，「小于取中间」：

**解集为 $\left(-\dfrac{1}{2},\, 2\right)$**。

---

### 例 3（拓展·含参）

**题目：** 解关于 $x$ 的不等式 $x^2 + ax + 1 > 0$ 恒成立，求实数 $a$ 的取值范围。

**解：**

令 $f(x) = x^2 + ax + 1$，$a_{\text{二次}} = 1 > 0$，开口向上。

$f(x) > 0$ 恒成立 $\Leftrightarrow$ 抛物线无交点 $\Leftrightarrow \Delta < 0$。

$$
\Delta = a^2 - 4 < 0 \Rightarrow -2 < a < 2
$$

**$a \in (-2, 2)$**。

> **课堂提示**：「恒成立」问题常转化为 $\Delta$ 与开口方向。

## 五、易错点与小结（15 min）

### 易错点

| 错因 | 正解 |
|------|------|
| $a < 0$ 仍用「大于两边」 | 先化为 $a > 0$ 或根据开口向下调整 |
| 忽略等号 | $\ge 0$ 要含端点（根处函数值为 0） |
| $\Delta < 0$ 时解集记错 | $a>0$ 则 $>0$ 为 $\mathbb{R}$，$<0$ 为 $\varnothing$ |
| 三个二次割裂 | 始终联系抛物线图象与交点 |

### 小结

- **三个二次**：函数图象是桥梁
- **$\Delta$**：判断根与交点个数
- **图象法**：求根 → 看开口 → 口诀写解集
- 恒成立：开口 + $\Delta$ 联合判断

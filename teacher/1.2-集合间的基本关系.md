# §1.2 集合间的基本关系

> **教材位置**：第一章 · §1.2 集合间的基本关系

> **前置知识**：§1.1 集合的概念，$\in$、$\notin$、列举法与描述法、空集 $\varnothing$

## 本节目标

1. 理解子集、真子集、集合相等的含义，正确使用符号 $\subseteq$、$\subset$、$=$；
2. 会用 Venn 图表示集合间的包含关系，掌握空集是任何集合的子集；
3. 能根据子集关系求参数或判断集合间的关系。

## 一、复习引入（15 min）

**复习提问：**

- 集合 $\{1, 2, 3\}$ 与 $\{3, 1, 2\}$ 是否表示同一集合？为什么？
- 空集 $\varnothing$ 与 $\{0\}$ 有何区别？$\varnothing$ 中有几个元素？

**情境：**

> 某校高一（1）班全体学生构成集合 $U$，参加篮球队的学生构成集合 $B$。  
> 篮球队里每一个人都是本班学生——即 $B$ 中的每个元素都属于 $U$。  
> 这种「一个集合的所有元素都在另一个集合里」的关系，就是**子集**关系。

---

## 二、新知讲解（45 min）

> 📖 以下定义、表述均摘自教材 **§1.2**，与课本逐字一致（符号已转为 LaTeX）。

### 2.1 子集（教材 P7）

**定义：** 一般地，对于两个集合 $A$，$B$，如果集合 $A$ 中任意一个元素都是集合 $B$ 中的元素，就称集合 $A$ 为集合 $B$ 的**子集**（subset），记作

$$A \subseteq B \quad \text{（或 } B \supseteq A\text{）}$$

读作“$A$ 包含于 $B$”（或“$B$ 包含 $A$”）。

### 2.2 Venn 图（教材 P7）

在数学中，我们经常用平面上封闭曲线的内部代表集合，这种图称为 **Venn 图**。

### 2.3 集合相等（教材 P7）

**定义：** 一般地，如果集合 $A$ 的任何一个元素都是集合 $B$ 的元素，同时集合 $B$ 的任何一个元素都是集合 $A$ 的元素，那么集合 $A$ 与集合 $B$ 相等，记作 $A = B$。

也就是说，若 $A \subseteq B$，且 $B \subseteq A$，则 $A = B$。

### 2.4 真子集（教材 P8）

**定义：** 如果集合 $A \subseteq B$，但存在元素 $x \in B$，且 $x \notin A$，就称集合 $A$ 是集合 $B$ 的**真子集**（proper subset），记作

$$A \subsetneqq B \quad \text{（或 } B \supsetneqq A\text{）}$$

### 2.5 空集（教材 P8）

**定义：** 一般地，我们把不含任何元素的集合叫做**空集**（empty set），记为 $\varnothing$，并规定：空集是任何集合的子集。

**结论（教材 P8）：**

（1）任何一个集合是它本身的子集，即 $A \subseteq A$；

（2）对于集合 $A$，$B$，$C$，如果 $A \subseteq B$，且 $B \subseteq C$，那么 $A \subseteq C$。

## 三、例题（40 min）

### 例 1（基础）

**题目：** 写出集合 $\{a, b\}$ 的所有子集，并指出其中的真子集。

**解：**

所有子集（共 $2^2 = 4$ 个）：

$$\varnothing,\quad \{a\},\quad \{b\},\quad \{a, b\}$$

真子集（不含自身）：

$$\varnothing,\quad \{a\},\quad \{b\}$$

共 3 个真子集。一般地，$n$ 元集共有 $2^n$ 个子集、$2^n - 1$ 个真子集。

---

### 例 2（综合）

**题目：** 已知 $A = \{x \mid x^2 - 3x + 2 = 0\}$，$B = \{1, 2, 3\}$，判断 $A$ 与 $B$ 的关系；若 $C = \{x \mid ax + 1 = 0\}$ 且 $C \subseteq A$，求实数 $a$ 的取值范围。

**解：**

由 $x^2 - 3x + 2 = 0$ 得 $x = 1$ 或 $x = 2$，故 $A = \{1, 2\}$。

因为 $A$ 中每个元素都在 $B$ 中，且 $3 \in B$ 但 $3 \notin A$，所以 **$A \subset B$**。

对于 $C \subseteq A$：

- 当 $a = 0$ 时，方程 $1 = 0$ 无解，$C = \varnothing \subseteq A$，成立。
- 当 $a \ne 0$ 时，$C = \left\{-\dfrac{1}{a}\right\}$，需 $-\dfrac{1}{a} \in \{1, 2\}$，得 $a = -1$ 或 $a = -\dfrac{1}{2}$。

综上，$a \in \left\{0,\, -1,\, -\dfrac{1}{2}\right\}$。

---

### 例 3（拓展）

**题目：** 已知集合 $A = \{x \mid x^2 + 2x + a = 0\}$，$B = \{x \mid x^2 + 2x + 3 = 0\}$。若 $A \subseteq B$，求实数 $a$ 的取值范围。

**解：**

先求 $B$：$x^2 + 2x + 3 = 0$ 的判别式 $\Delta = 4 - 12 < 0$，故 **$B = \varnothing$**。

要使 $A \subseteq B$，只有 $A = \varnothing$ 一种可能（因为 $\varnothing$ 是唯一的空集子集）。

- 当 $\Delta = 4 - 4a < 0$，即 $a > 1$ 时，$A = \varnothing$，满足。
- 当 $\Delta = 0$，$a = 1$ 时，$A = \{-1\} \ne \varnothing$，而 $\{-1\} \not\subseteq \varnothing$，不满足。
- 当 $\Delta > 0$ 时，$A$ 有两个元素，更不可能 $\subseteq \varnothing$。

故 **$a > 1$**。

> **课堂提示**：空集是任何集合的子集，但「$A \subseteq \varnothing$」迫使 $A = \varnothing$，这是含参子集问题的常见陷阱。

## 四、课堂练习（25 min）

1. 用符号 $\subseteq$、$\subset$ 或 $=$ 填空：$\varnothing$ ______ $\{1\}$；$\{1\}$ ______ $\{1, 2\}$；$\{1, 2\}$ ______ $\{2, 1\}$。

2. 集合 $\{1, 2, 3\}$ 共有 ______ 个子集，其中真子集有 ______ 个。

3. 若 $A = \{1, 3\}$，$B = \{x \mid x^2 - 4x + 3 = 0\}$，则 $A$ 与 $B$ 的关系是 ______。

4. 已知 $A = \{x \mid 2x - 1 < 3\}$，$B = \{x \mid x < 2\}$，判断 $A$ 与 $B$ 的关系。

5. **思考**：若 $A \subseteq B$ 且 $B \subseteq A$，能否推出 $A = B$？为什么？

---

## 五、易错点与小结（15 min）

### 易错点

| 错因 | 正解 |
|------|------|
| 把 $\in$ 与 $\subseteq$ 混用 | $\{1\} \subseteq \{1,2\}$，但 $1 \in \{1,2\}$ |
| 认为 $\varnothing \subset \varnothing$ | 真子集要求 $B$ 中有元素不属于 $A$；空集不是自身的真子集 |
| 忽略 $C = \varnothing$ 的情况 | 含参子集问题要先讨论方程无解（空集） |
| $A \subseteq B$ 时漏掉 $A = B$ | $\subseteq$ 包含相等；$\subset$ 不包含相等 |

### 小结

- **子集** $A \subseteq B$：$A$ 中元素都在 $B$ 中
- **真子集** $A \subset B$：$A \subseteq B$ 且 $A \ne B$
- **相等** $A = B$：$A \subseteq B$ 且 $B \subseteq A$
- $\varnothing \subseteq A$ 恒成立；Venn 图直观表示包含关系

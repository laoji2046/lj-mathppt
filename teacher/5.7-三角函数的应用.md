### 2.1 三角函数模型的简单应用（教材 P242–P246）

**简谐运动（教材 P242）：** 弹簧振子、单摆等周期现象可用 $y = A\sin(\omega x + arphi)$ 刻画，其中 $A$ 为振幅，$\omega$ 为角频率，$arphi$ 为初相。

**潮汐、交流电（教材 P243–P245）：** 许多自然现象和社会现象具有周期性，可用三角函数建立模型，通过观察数据确定参数，预测变化规律。

### 2.2 建立三角函数模型的基本过程（教材 P246）

1. 理解实际问题中的周期现象；  
2. 确定自变量与因变量，选择 $y = A\sin(\omega x + arphi) + b$ 等形式；  
3. 根据已知数据求 $A, \omega, arphi, b$；  
4. 利用模型预测或解释现象，检验合理性。

## 三、例题（40 min）

### 例 1（基础·简谐振动）

**题目：** 某弹簧振子位移 $s$（cm）与时间 $t$（s）满足 $s = 5\sin\left(4t + \dfrac{\pi}{3}\right)$。求振幅、周期、初相，以及 $t = 0$ 时的位移。

**解：**

振幅 $A = 5\,\text{cm}$；$\omega = 4$，周期 $T = \dfrac{2\pi}{4} = \dfrac{\pi}{2}\,\text{s}$；初相 $\varphi = \dfrac{\pi}{3}$。

$t = 0$ 时：$s = 5\sin\dfrac{\pi}{3} = \dfrac{5\sqrt{3}}{2}\,\text{cm}$。

---

### 例 2（综合·潮汐）

**题目：** 某港口潮高 $h$（m）近似为 $h = 3 + 2\sin\dfrac{\pi t}{6}$（$t$ 为从 0:00 起的小时数，$0 \le t \le 24$）。求最高潮、最低潮及出现时刻；潮高不低于 $4\,\text{m}$ 的时间段。

**解：**

$h_{\max} = 3 + 2 = 5\,\text{m}$（$\sin\dfrac{\pi t}{6} = 1$，$t = 3 + 12k$，在 $[0,24]$ 内为 $t = 3$ 或 $15$）；

$h_{\min} = 1\,\text{m}$（$t = 9$ 或 $21$）。

$3 + 2\sin\dfrac{\pi t}{6} \ge 4 \Rightarrow \sin\dfrac{\pi t}{6} \ge \dfrac{1}{2}$。

在 $[0, 24]$ 内：$\dfrac{\pi}{6} \le \dfrac{\pi t}{6} \le \dfrac{5\pi}{6}$ 或 $\dfrac{13\pi}{6} \le \dfrac{\pi t}{6} \le \dfrac{17\pi}{6}$，即 $1 \le t \le 5$ 或 $13 \le t \le 17$（小时）。

---

### 例 3（综合·建模）

**题目：** 某地一天中气温 $T$（$^\circ\text{C}$）近似按正弦变化：$6:00$ 最低 $14^\circ\text{C}$，$14:00$ 最高 $26^\circ\text{C}$。用 $t$ 表示从 6:00 起的小时数，建立 $T$ 关于 $t$ 的函数模型。

**解：**

中心值 $k = \dfrac{14+26}{2} = 20$，振幅 $A = \dfrac{26-14}{2} = 6$。

从最低到最高历时 $8\,\text{h}$，为半个周期，故 $T_{\text{周期}} = 16\,\text{h}$，$\omega = \dfrac{2\pi}{16} = \dfrac{\pi}{8}$。

$t=0$ 时最低，用 $T = 20 + 6\sin\left(\dfrac{\pi}{8}t - \dfrac{\pi}{2}\right)$ 或 $T = 20 - 6\cos\dfrac{\pi}{8}t$。

验证：$t=8$ 时 $T = 20 + 6\sin\dfrac{\pi}{2} = 26$ ✓。

---

### 例 4（拓展）

**题目：** 交流电电压 $u = 220\sqrt{2}\sin(100\pi t)$（V），求频率、周期及 $t = 0.01\,\text{s}$ 时的电压。

**解：**

$\omega = 100\pi$，$T = \dfrac{2\pi}{100\pi} = 0.02\,\text{s}$，$f = \dfrac{1}{T} = 50\,\text{Hz}$。

$t = 0.01 = \dfrac{T}{2}$，$u = 220\sqrt{2}\sin\dfrac{\pi}{2} = 220\sqrt{2}\,\text{V}$（瞬时值最大）。

## 五、易错点与小结（15 min）

### 易错点

| 错因 | 正解 |
|------|------|
| 把 $h_0 + A\sin(\cdots)$ 的振幅当成 $h_0 + A$ | 振幅仍是 $A$；最大值 $h_0+A$，最小值 $h_0-A$ |
| 周期与半周期混淆 | 最高到最低（或相反）往往只差**半个**周期 |
| 时间单位与 $\omega$ 不匹配 | $t$ 用小时则 $T$ 也用小时算 $\omega$ |
| 实际问题忽略定义域 | 如 $0 \le t \le 24$，解不等式要截在范围内 |

### 小结

- 模型：$y = A\sin(\omega t + \varphi) + k$（简谐振动、潮汐、气温等）
- 参数：$A$ 振幅，$T = \dfrac{2\pi}{\omega}$ 周期，$\varphi$ 初相，$k$ 中心线
- 步骤：识周期 → 定 $A,k,\omega$ → 定 $\varphi$ → 解实际问题

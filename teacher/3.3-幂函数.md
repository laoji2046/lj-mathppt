# §3.3 幂函数

> **教材位置**：第三章 · §3.3 幂函数  
> **建议时长**：约 120 min（2 h）  
> **前置知识**：§3.1 函数概念、§3.2 单调性与奇偶性；指数运算

---

## 本节目标

1. 理解幂函数 $y = x^\alpha$（$\alpha \in \mathbb{R}$）的定义，能识别幂函数；
2. 掌握 $\alpha = 1, 2, -1, \dfrac{1}{2}$ 等常见幂函数的图象与性质；
3. 能利用幂函数性质比较大小、讨论参数范围。

---

## 一、复习引入（15 min）

**复习提问：**

- $y = x^2$、$y = \sqrt{x}$、$y = \dfrac{1}{x}$ 有什么共同点？指数位置有何特点？
- 第一象限内，$y = x^2$ 与 $y = x$ 谁增长更快（$x>1$ 时）？

**情境：**

> 正方形边长 $x$ 与面积 $S = x^2$、周长 $C = 4x$ 都是「底数相同、指数不同」的幂形式——这类函数统称为**幂函数**。

---

## 二、新知讲解（45 min）

> 📖 以下定义、表述均摘自教材 **§3.3**，与课本逐字一致（符号已转为 LaTeX）。

### 2.1 幂函数的定义（教材 P89）

实际上，形如 $y = x^\alpha$ 的函数，都是以幂的底数为自变量；幂的指数都是常数。

一般地，函数 $y = x^\alpha$ 叫做**幂函数**（power function），其中 $x$ 是自变量，$\alpha$ 是常数。

对于幂函数，我们只研究 $\alpha = 1$，$2$，$3$，$\dfrac{1}{2}$，$-1$ 时的图象与性质。

### 2.2 五个常见幂函数（教材 P90–P91）

在同一坐标系中，函数 $y = x$，$y = x^2$，$y = x^3$，$y = x^{\frac{1}{2}}$ 和 $y = x^{-1}$ 的图象都通过点 $(1,1)$。

通过图象与解析式，可以得到：

**（1）** 函数 $y = x$，$y = x^3$，$y = x^{-1}$ 是奇函数，函数 $y = x^2$ 是偶函数；

**（2）** 在区间 $(0, +\infty)$ 上，函数 $y = x$，$y = x^2$，$y = x^3$，$y = x^{\frac{1}{2}}$ 单调递增，函数 $y = x^{-1}$ 单调递减；

**（3）** 在第一象限内，函数 $y = x^{-1}$ 的图象向上与 $y$ 轴无限接近，向右与 $x$ 轴无限接近。

## 三、例题（40 min）

### 例 1（识别与性质）

**题目：** 下列函数是幂函数的是（  ），并说明理由。

A. $y = x^{\frac{2}{3}}$  
B. $y = 3x^2$  
C. $y = x + 1$  
D. $y = (\dfrac{1}{2})^x$

**解：**

只有 **A** 是幂函数，形如 $y = x^\alpha$，系数为 1。  
B 系数为 3；C 含常数项；D 指数函数（底数为常数，指数为自变量）。

---

### 例 2（图象与大小比较）

**题目：** 比较下列各组数的大小：

（1）$2^{\frac{2}{3}}$ 与 $2^{\frac{3}{4}}$；  
（2）$0.3^2$ 与 $0.3^{\frac{1}{2}}$；  
（3）$(\dfrac{1}{2})^{-\frac{1}{2}}$ 与 $(\dfrac{1}{3})^{-\frac{1}{2}}$。

**解：**

（1）考察 $y = 2^x$ 在 $(0,+\infty)$ 上增（指数函数，可类比），$\dfrac{2}{3} < \dfrac{3}{4}$，故 $2^{\frac{2}{3}} < 2^{\frac{3}{4}}$。

或用幂函数：固定底 $a>1$，指数越大值越大。

（2）底 $0 < 0.3 < 1$，函数 $y = 0.3^x$ 减，$\dfrac{1}{2} < 2$，故 $0.3^{\frac{1}{2}} > 0.3^2$。

（3）$(\dfrac{1}{2})^{-\frac{1}{2}} = 2^{\frac{1}{2}}$，$(\dfrac{1}{3})^{-\frac{1}{2}} = 3^{\frac{1}{2}}$。  
$y = x^{\frac{1}{2}}$ 在 $(0,+\infty)$ 增，$2 < 3$，故 $2^{\frac{1}{2}} < 3^{\frac{1}{2}}$，即 $(\dfrac{1}{2})^{-\frac{1}{2}} < (\dfrac{1}{3})^{-\frac{1}{2}}$。

---

### 例 3（综合）

**题目：** 幂函数 $f(x) = x^\alpha$ 的图象过点 $(2, \dfrac{1}{4})$，求 $\alpha$，并判断 $f(x)$ 在 $(0,+\infty)$ 上的单调性。

**解：**

$f(2) = 2^\alpha = \dfrac{1}{4} = 2^{-2}$，故 $\alpha = -2$。

$f(x) = x^{-2} = \dfrac{1}{x^2}$，在 $(0,+\infty)$ 上，$x$ 增大时 $x^2$ 增大，$\dfrac{1}{x^2}$ 减小，故 **单调递减**。

也可用定义：设 $0 < x_1 < x_2$，$f(x_1) - f(x_2) = \dfrac{x_2^2 - x_1^2}{x_1^2 x_2^2} > 0$，故减。

## 四、课堂练习（25 min）

1. 幂函数 $y = x^{-3}$ 的定义域为 ______，奇偶性为 ______。

2. 函数 $y = x^{\frac{1}{3}}$ 的图象过点 $(8, m)$，则 $m =$ ______。

3. 比较大小：$1.1^{\frac{1}{2}}$ ______ $1.1^2$（填 $>$、$<$ 或 $=$）。

4. 在同一坐标系中，$\alpha=1,2,-1$ 时 $y=x^\alpha$ 在第一象限内，$\alpha$ 越大图象越靠上（$x>1$）——判断正误并说明。

5. **思考**：$y = x^0$（$x \ne 0$）是幂函数吗？图象如何？

## 五、易错点与小结（15 min）

### 易错点

| 错因 | 正解 |
|------|------|
| 把 $y=2^x$ 当幂函数 | 幂函数底数为 $x$，指数为常数 |
| $y=x^{-1}$ 定义域漏 $x\ne0$ | 负指数时分母不为 0 |
| 比较大小未统一底或指数 | 利用单调性，先化为同底或同指数 |
| $y=x^{\frac{1}{2}}$ 定义域写成 $\mathbb{R}$ | 偶次根式，$x \ge 0$ |

### 小结

- 幂函数：$y = x^\alpha$，系数为 1
- 五个代表：$1, 2, 3, \dfrac{1}{2}, -1$ 的图象与性质
- 公共点 $(1,1)$；第一象限 $\alpha$ 大小与图象位置关系
- 应用：比大小、求参数、讨论单调性

使用帮助

① 主界面布局

顶栏为菜单栏；下方为水平工具栏；左侧为幻灯片缩略面板、中央为 1280×720 编辑画布、右侧为属性面板；底部为状态栏。

② 顶部菜单栏

新建（Ctrl+N）、打开（Ctrl+O）、保存（Ctrl+S）、导出（Ctrl+E，HTML / PDF / PNG）、撤销重做、主题、模板库、版本、演示、帮助。

③ 水平工具栏（插入元素）

选择、文本（T）、形状（S）、图片、图表、表格、图标、思维导图、笔、线、箭头、嵌入、GeoGebra、Desmos、数学公式。点击后在画布上放置并编辑。

④ 幻灯片面板 / 缩略条

左侧缩略图列出全部幻灯片，可选中、拖拽排序、添加/删除、进入章节与子页。

⑤ 新建 / 保存

新建一份演示文稿；保存为 .revealslidr.json 项目文件，支持系统原生另存为对话框。

⑥ 文本编辑

双击文本框输入文字；选中后右侧属性面板可调字体、字号、颜色、对齐、旋转与大小。

⑦ 形状 / 几何图形

插入矩形、椭圆、三角形、直线、箭头、多边形、五角星，以及抛物线、正弦、坐标系、Venn 图等教学图形。

⑧ 数学公式

用 LaTeX 语法输入公式（x^2、\frac{1}{2}、\R实数集、\set{}{}集合），MathJax 实时渲染。

⑨ GeoGebra / Desmos 互动

插入可交互数学演示（绘图、几何、3D 等）或 Desmos 计算器，需联网加载 CDN 引擎。

⑩ 在线嵌入（HTML / 代码 / 网页）

嵌入任意 URL、网页、PDF 或代码块内容（iframe），可在演示中交互。

⑪ 模板库与主题

模板库一键套用基础布局 / 教学模板 / 专业模板 / 高中数学讲义；主题切换整套配色与字体。

⑫ 设置面板

配置标题、描述、画布尺寸、边距、导航、自动播放、页码、GeoGebra 离线、Desmos 密钥；可修改页面背景色。

⑬ 演示模式

F5 或顶栏 演示 进入全屏，方向键翻页、Esc 退出；底部控制条含上一页/下一页、概览、自动播放、循环、暂停、全屏、计时器、备注与演讲者视图。

更多操作详见随附《LJ-PPT 使用手册》

-0.18em

调节行内公式（如 $x^2$）相对同一行中文文字的上下位置：数值越小越靠下，越大越靠上。拖动即时预览，保存后随项目生效，导出的 HTML 也会带上该设置。
